How links are inferred

A proof is connected to a conjecture when its name, programme folder or LaTeX statement contains a catalogue keyword, or when the whole folder is a strong contextual prior. Each edge records the evidence and a confidence level: strong ≥ 6, moderate 3–5, contextual 2.

A dashed dependency edge is added when a matched proof's statement or proof body mentions the name of an otherwise unmatched proof, preferring references in the same file or programme folder.

Unmatched proofs are grey; use the confidence selector to remove weaker suggestions.
