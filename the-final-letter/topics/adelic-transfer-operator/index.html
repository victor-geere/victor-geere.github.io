Adelic transfer operator

A reconstructed research programme: archived thesis outline, local formal core, exact computation, and open global claim

Status. The source is a thesis outline. This reconstruction formalises only the local MTC and Fredholm bookkeeping that the outline actually defines. The global Riemann-hypothesis proof claim is archived and is not presented as a theorem. The full ledger is in README.md.

Provenance and status

Primary source: archive/maths/rh/research/adelic-transfer-operator/thesis-complete-outline.md. The same folder contains a local RT outline and a prompt tree. Inventory entry: Scraps item 7; topic index: topics/.

The folder contains outlines and prompts, not a completed proof. The complete outline claims a "complete and unconditional proof of the Riemann Hypothesis"; that claim is archived and is not treated as established here. The source overlaps inventory item 21 (rh-mtc), which uses the same prime-indexed MTC construction.

This reconstruction keeps only the finite local objects: the modular tensor category C_p = SU(2)_{p−2}, the RT weight p^{−n}, and the geometric-series bookkeeping behind the local Fredholm factor (1 − p^{−s})^{−1}. The adelic operator, restricted tensor product, global determinant, functional equation, Ruelle-pressure exclusion, winding-number count, and RH conclusion remain source claims or open items.

What the source claims

  1. A self-adjoint adelic transfer operator L_s whose spectrum encodes the nontrivial zeros of the Riemann zeta function.
  2. Local building blocks from C_p = SU(2)_{p−2}.
  3. RT_{C_p}(β) = p^{−n} for the framed braid of a length-n periodic orbit on the Bruhat–Tits tree T_p.
  4. Local Fredholm determinants det(1 − L_{p,s}) = (1 − p^{−s})^{−1}.
  5. A restricted tensor product over all places whose determinant is ζ̂(s) e^{P(s)}.
  6. A functional equation from modular invariance of local theta functions.
  7. A Ruelle-pressure argument excluding zeros off the critical line.
  8. Unitarity on Re(s) = 1/2 and a winding-number computation reproducing Riemann–von Mangoldt.

The local outline states the RT-weight claim as a standalone theorem and describes a proof via Seifert-fibred manifolds, the Verlinde formula, a Gauss sum, and Landsberg–Schaar reciprocity. It also promises numerical verification for p ≤ 17, n ≤ 8. None of these proofs is present in the archive, and none is formalised here.

The S-matrix involution is checked through the exact product-to-sum identity

(S²)_{ac} = (1/p) [ C(a−c) − C(a+c) ],
C(k) = ∑_{b=1}^{p−1} cos(π k b / p),

with C(0) = p − 1, C(k) = −1 for nonzero even k, and C(k) = 0 for odd k. This avoids relying on sympy's incomplete trigonometric simplification for p ≥ 7.

Open items and known gaps

  1. The source is an outline, not a proof. The abstract's RH claim is unsupported by the archived text. It remains an archived claim.
  2. The local RT theorem is not reconstructed. The braid, framing, RT invariant, and Gauss-sum evaluation are absent. T1–T4 and C1–C4 only verify the finite MTC data that such a proof would use.
  3. The local Fredholm identity is not reconstructed. T5–T7 and C5–C6 formalise the scalar geometric series; the operator L_{p,s} and its determinant are not defined.
  4. The orbit count needs reconciliation. p^n + 1 does not match the periodic points of the boundary map z ↦ pz as stated. This should be resolved before the local theorem is cited.
  5. The global argument is entirely open. Restricted tensor products, determinant factorisation, functional equation, Ruelle exclusion, and zero counting remain source claims or open items O3–O8.
  6. The Verlinde check is small. C8 verifies the stated formula for p = 3, 5 only; no general proof of the Verlinde formula is attempted.
