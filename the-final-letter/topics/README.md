# Research topics

One folder per item in the [scraps inventory](../scraps.html), grouped under `the-final-letter/topics/` so the numbered programme sections and the evidence/Lean folders stay uncluttered. Each folder is a reconstructed programme with a `README.md`, an `index.html`, a sympy computation layer with pytest tests, and a Lean formal core. The standard is [PROGRAMME-STANDARD.md](PROGRAMME-STANDARD.md); the browser index is [index.html](index.html); the theorem/test/Lean ledger is [STATUS.md](STATUS.md).

A reconstructed programme does not make the source's claims true. Every dossier separates **Theorem** (Lean-proved), **Computation** (tested), **Source claim** (archived, not adopted), and **Open/conjecture**.

The table also carries the three programme objectives: item 1 (Riemann wall), item 2 (parity wall), and item 45 (Objective III, certified partial-sum-plus-tail evaluation).

## How to use these folders

1. Start from the source linked in the folder README; do not harvest from a duplicate version when a canonical one exists.
2. Separate proved results from conditional, open, refuted, and archived claims.
3. Promote a topic only when it has a stable statement list, not merely a large file count.
4. Keep the canonical paper and the [withdrawn-and-refuted ledger](../summary/12-open-problems/withdrawn-and-refuted.md) as the authority.
