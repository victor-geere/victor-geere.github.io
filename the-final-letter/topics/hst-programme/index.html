Provenance and scope

The archived landing page is a duplicate programme hub. It presents the same eight-programme HST corpus catalogued under item 17: greedy expansion of angles, the Haar tree and HST isometry, the transfer operator, the Fredholm determinant identity, harmonic sine L-functions, and the speculative Programme IIX route to GRH. Item 27 is the hub page; the papers themselves are in archive/maths/hst/, and item 17 names the research guide as its source.

This folder therefore does not invent a second programme. It reconstructs the finite mathematical seed that both items share — the greedy harmonic expansion of a normalised angle — and cites the duplicate for everything else. The landing page is prose and link metadata, not a proof document; its mathematical claims are inherited from the linked papers, principally 01-hst-proof-step.tex.

Two source-status facts matter for honesty. First, the landing page calls Programmes I–V fully rigorous, but its own Fredholm-proof card says the proof “contains gaps that need to be filled before it can be used in this programme”, and Programme IIX is labelled speculative with an explicitly open monotonicity inequality. The “rigorous” labels are recorded below as source claims, not verified here.

Second, the research guide for item 17 states the digit recursion as δn = ⌊(n+2) rn⌋ while calling the digits binary. That recursion is not binary: for x = 9/10 it gives δ1 = 2. Programme I and the landing page instead use the binary rule below, which is the rule the Haar-tree construction needs. The discrepancy is tested, not hidden.

Reconstructed objects and notation

Work with the normalised angle x = θ/π ∈ [0,1] and the harmonic fractions

d_n = 1/(n+2),        n = 0,1,2,…

The binary greedy recursion is

r_0 = x,
δ_n = 1  if d_n ≤ r_n,   δ_n = 0 otherwise,
r_{n+1} = r_n − δ_n d_n.

The finite greedy partial sum is s_N = Σn<N δ_n d_n, and the residual is r_N = x − s_N. The programme's series claim is x = Σn≥0 δ_n/(n+2).

Python layer

The module uses exact sympy rationals throughout and no floating point; mpmath is not needed.

import sympy as sp
from programme import expansion, greedy_digits, residual, sine_reconstruction

greedy_digits(sp.Rational(1, 3), 5)        # [0, 1, 0, 0, 0]
residual(sp.Rational(3, 7), 230)           # 0
expansion(sp.Rational(1))                  # digits (1, 1, 0, 0, 1), residual 0
sine_reconstruction(sp.Rational(1, 3), 2)  # sqrt(3)/2

Open items and gaps

  1. Haar tree and HST isometry are absent. The source's Programme II–III claims (orthonormal Haar basis, isometric isomorphism, Dirichlet-series convergence) are not formalised. A faithful reconstruction would need a measurable-space development of the cylinder intervals and L² bases.
  2. The Fredholm determinant identity is unverified. The landing page calls it rigorous, the linked proof page calls itself incomplete, and this reconstruction has no formalisation of L_s, Mayer–Efrat theory, or regularised determinants. It remains an archived claim.
  3. The Programme IIX monotonicity inequality is open. The inequality Im tr((I−L1/2+it,χ)−1 dL/dt) ≥ 0 is the source's own declared open problem and is labelled speculative. No RH or GRH conclusion is drawn.
  4. Source digit conventions conflict. The binary rule of Programme I and the floor rule of the research guide disagree (C6). This reconstruction uses the binary rule because the Haar tree and the formal core depend on it; the source needs an explicit correction.
  5. Endpoint and threshold formalisation. T6–T7 assume x < 1; x = 1 is only computed exactly. The threshold functions θn* and digit monotonicity in θ are not formalised.
  6. Status review vs landing page. The corpus's “fully rigorous” claim and the “incomplete proof” label have not been reconciled; the canonical record should settle which applies to Programme V.
