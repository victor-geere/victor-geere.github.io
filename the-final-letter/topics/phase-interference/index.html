Phase interference

A reconstructed finite kernel and phase core — a duplicate fragment of the GHD programme

Status. The finite kernel and phase algebra is reconstructed and checked. The source's generalised Riemann hypothesis claim is an archived claim, not a theorem of this reconstruction. The full dossier is in README.md.

Provenance and status

The source is archive/maths/phase-interference/proof.md (Victor Geere, May 2026), a 132-line proof draft self-labelled “COMPLETE & RIGOROUS”. It is a compressed duplicate of the GHD/correlation-kernel corpus. It retracts an earlier false global indicator δ_n(θ) = 1_{[α_n,π]}(θ) and earlier “invalid closed-form kernel formulas”, and replaces them with the true recursive selection rule. That correction is the useful content; the spectral argument of §12–§13 is asserted, not derived. The conclusion — GRH — is recorded below as an archived claim.

Primary topics: greedy harmonic decomposition (item 11) and GHD correlation kernel (item 25). This folder does not supersede either.

Open items and gaps

  1. The spectral argument is absent: no checkable statement of M_χ, the Fredholm determinant, or the determinant–zero equivalence.
  2. GRH is an archived claim, not a theorem; nothing here supports it beyond elementary finite identities.
  3. The kernel is not formalised in Lean; only the phase algebra is. The finite integration lives in Python.
  4. Interference is verified only two-term; no matrix-level cancellation theorem is claimed.
  5. The topic duplicates the primary GHD material and should be read as a fragment of it.
