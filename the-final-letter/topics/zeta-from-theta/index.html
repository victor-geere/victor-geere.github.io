Zeta from theta — an FE-independent development of ζ

Status: construction complete. The theta layer now lives here, the standalone object zetaTheta is defined and shown to satisfy the functional equation, it is identified with Mathlib's riemannZeta, the trivial zeros and their removable limit are handled, and a constant-level provenance audit is recorded. Nothing here proves the Riemann hypothesis, and nothing here is a new theorem: the payoff is architectural.

The loop

Mathlib defines riemannZeta := hurwitzZetaEven 0 and proves the functional equation through Hurwitz zeta (completedRiemannZeta_one_sub ← completedHurwitzZetaEven_one_sub). So any argument that needs the functional equation while developing Hurwitz-zeta material depends on that very development. In a formal system this is not a contradiction — a cycle simply means the proof is unavailable — but it blocks using the functional equation as a tool.

The theta work (V1–V40) proved Λ(1 − s) = Λ(s) with a dependency cone free of the functional equation: Poisson summation contains no occurrence of riemannZeta; the Mellin Dirichlet file has no one_sub; Gammaℝ_div_Gammaℝ_one_sub comes from Gamma reflection; riemannZeta_def_of_ne_zero is a definitional rewrite. This topic removes the last dependence, which was the object itself.

The construction

  1. Mellin, Re s > 1: Λ_θ(s) = Γℝ(s)·Σ n−s via hasSum_mellin_pi_mul.
  2. Split at 1 and substitute t ↦ 1/t using θ(1/t) = √t·θ(t): Λ_θ(s) = ∫₁∞ ψ(t)(ts/2−1 + t(1−s)/2−1)dt + 1/(s−1) − 1/s, manifestly symmetric. This is LambdaTheta.
  3. Continue: the right-hand side is analytic on ℂ ∖ {0,1} (differentiableAt_LambdaTheta).
  4. Define ζ_θ := Λ_θ/Γℝ off the Γℝ zeros, with the trivial zeros handled separately (zetaTheta).
  5. Identify with the Dirichlet series, hence with riemannZeta on the overlap, and transfer the functional equation.
