What the source is

paper.md is a self-contained GDST paper. Its abstract and §3 claim a proof of the Riemann hypothesis in three stages: a greedy harmonic expansion of θ/π; a transfer operator L_s on H²(𝔻) with a Fredholm determinant identity det(I − L_s) = ζ(s)/ζ(2s)·e^{P(s)}; and a family of Jacobi matrices J_σ whose spectra are σ-independent, making J_{1/2} self-adjoint and forcing every non-trivial zero onto Re s = 1/2.

The paper is candid about its own gaps: §5 lists twelve analytic inputs — trace-class property, similarity to the Mayer operator, the telescoping trace sum, the determinant identity, the kernel closed form, the Jacobi spectral theory, the Hausdorff moment problem and σ-independence — as tasks “marked as axioms or sorry in the Isabelle formalisation”. Those are the load-bearing steps, so the global RH claim is an archived claim, not a theorem.

There are also elementary errors in §1 that the archived status had not caught. Two of them are fatal to the paper’s later sections, and this folder records them as errata with exact counterexamples rather than silently repairing them. The salvageable mathematical content is the finite greedy recursion and the finite selected/rejected split of §2.1; that is what is formalised below.

Reconstructed objects

Normalise the target to x = θ/π ∈ [0, 1]. The harmonic fractions are α_n = 1/(n+2). The greedy pass over indices 0, …, N−1 is the recursion

r_0 = x,      δ_n = 1 iff α_n ≤ r_n,      r_{n+1} = r_n − δ_n α_n.
ObjectDefinition
Harmonic fractionα n = 1/(n+2)
Greedy remainderrun x N = r_N, after processing 0, …, N−1
Selection wordδ n = 1 iff α n ≤ run x n
Selected prefixE_N(w) = Σ_{k<N, δ_k=1} w k
Rejected prefixΩ_N(w) = Σ_{k<N, δ_k=0} w k
Full prefixH_N(w) = Σ_{k<N} w k
GDST weightw k = (k+2)^(−s) on Re s > 0

The exact finite core is:

  1. greedy invariant r_N = x − E_N(α), i.e. x = E_N(α) + r_N (the source’s equation (1.1));
  2. selected/rejected split E_N(w) + Ω_N(w) = H_N(w) for every weight w (the finite form of ζ(s) − 1 = E(θ,s) + Ω(θ,s)).

Both are proved in Lean for arbitrary N; neither needs the infinite series. The source’s digit monotonicity is not available, because it is false.

Errata with exact evidence

  • E1 — Lemma 1.3 is false as stated. It claims r_n < 1/(n+2) for all n ≥ 0. At x = 1, r_0 = 1/2, not < 1/2. The correct sharp statement after N processed indices is r_N ≤ 1/(N+1), with equality only at N = 1, x = 1; C4 tests the repaired bound.
  • E2 — Theorem 1.7 (digit monotonicity) is false. 999/2000 < 1/2, but δ_1(999/2000) = 1 while δ_1(1/2) = 0: at 1/2 the first fraction is taken, leaving remainder 0; just below 1/2 the first fraction is skipped, so the second one fits. C7 checks this exactly.
  • E3 — Theorem 1.9(2) is false. δ_1(x) = 1 exactly on [1/3, 1/2), so θ_1* = 1/3; but δ_1(1/2) = 0, contradicting the claimed up-set {θ : δ_1(θ) = 1} = [θ_1*, π].
  • E4 — Theorem 1.14 is inconsistent. The stated diagonal formula is negative at n = 0 and disagrees with the direct threshold integral. The “proof sketch” defers the computation to a companion paper.
  • E5 — Theorem 1.6’s proof has an invalid step. It writes r_m < r_{m−1} − 1/(m+2) although the algorithm gives equality, and the claimed lower bound on m' does not follow. The super-exponential claim is left open here, not refuted.
  • E6 — §3.3 Step 4 is a non sequitur. From ρ − 1/2 ∈ spec(J_{1/2}) ⊂ ℝ the paper concludes Im ρ = 0 or Re ρ = 1/2. An element of ℝ has zero imaginary part, so the argument yields Im ρ = 0 (impossible for a non-trivial zero only if one already knows the zeros are non-real), not Re ρ = 1/2.

Open items and known gaps

  1. No global claim is formalised. The transfer operator, its trace-class property, the Fredholm determinant, the Jacobi matrices, the moment problem and the RH conclusion are all far beyond this finite core. The appendix’s twelve tasks remain open.
  2. The source is not merely incomplete; parts are wrong. C7 and E1–E6 are exact, checkable failures, not gaps in the reconstruction. Any future use of the paper’s §1.2–§1.3 must replace the monotonicity and threshold lemmas.
  3. The finite split is word-level, not greedy-specific. T6 holds for every binary selection word; the greedy recursion enters T3–T5 and C1–C7. This mirrors, but does not duplicate, the twin-series folder (item 24), which keeps the arbitrary-word complement as its core.
  4. The companion papers are unaudited. paper1.md–paper4.md and the MiniProof parser are recorded as provenance only; no claim from them is adopted.
  5. Consequence for the inventory. Item 32 is an archived claim. The readable salvage is the finite greedy layer; the RH programme is not advanced by this folder.
