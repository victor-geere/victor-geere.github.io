What the programme is

The HST programme attempts a Hilbert–Pólya-style spectral theory of the Riemann zeta function built from Victor Geere's greedy harmonic reconstruction of the sine. Its elementary starting point is small and genuine: the harmonic angles

αn = π/(n+2),   n = 0,1,2,…

serve both as the step sizes of a greedy expansion of an angle θ ∈ [0,π] and as the right-child lengths of a binary tree of cylinder intervals. Haar wavelets are attached to the split nodes, and the resulting coefficient map is called the Harmonic Sine Transform.

The word “programme” is load-bearing. The archive presents a coherent narrative — Haar basis, isometric HST, transfer operator ℒs, Fredholm determinant det(I−ℒs) = ζ(s)/ζ(2s)·eP(s), Weil explicit formula, spectral flow, Hilbert–Pólya and a GRH paper — but the load-bearing analytic steps are proof sketches or unsupported claims. This folder reconstructs the part that can actually be proved and computed.

Two different digit recursions. The guide's Section 3.1 defines r0 = θ/π, δn = ⌊(n+2)rn⌋, rn+1 = (n+2)rn − δn, which allows digits δn ≥ 2. harmonic-tree-haar.tex equation (1) instead uses the residual-subtraction rule δn = Θ(θ − An − αn), An+1 = An + δnαn, with digits in {0,1}. These are different algorithms. This reconstruction follows the residual-subtraction rule, because it is the rule used for the Haar tree, the threshold angles, and the pilot greedy harmonic decomposition. The guide also cites a greedy-harmonic-zeta-function.tex that is not in this folder, so the “eight-paper” count does not correspond to eight consistent, self-contained papers.

Reconstructed objects and notation

Angles are written θ; it is often convenient to use t = θ/π ∈ [0,1], so that αn/π = 1/(n+2).

ObjectReconstruction definition
Harmonic angleαn = π/(n+2)
Accumulated angleA0 = 0, An+1 = An + δnαn
Greedy digitδn(θ) = 1 if αn ≤ θ − An, else 0
Thresholdθn* = inf{θ : δn(θ) = 1}
Cylinder intervalIε = {θ : δk(θ) = εk, k < |ε|}
Split nodea node of length ℓ with αn < ℓ; right child length αn, left child length ℓ − αn
Haar wavelet (reconstructed)on a node of length L = a + b (left a, right b): ψ = −√(b/(aL))·1L + √(a/(bL))·1R
Accumulated massMn(θ) = Σk≤n δk(θ)/(k+2), so An = πMn

The source's displayed wavelet (equation (5) of harmonic-tree-haar.tex) uses coefficients 1/√αn on the right child and −1/√(ℓ−αn) on the left. That formula has squared norm 2, not 1, and its mean is √αn − √(ℓ−αn), which vanishes only when the children have equal length. The reconstruction uses the correctly normalised zero-mean wavelet above. The repair is proved in Lean and checked exactly in Python.

Two further tests cover the exact angle sequence and the endpoint/invalid-input edge cases: test_alpha_sequence_is_exact_and_strictly_decreasing and test_greedy_digits_exact_and_edge_cases.

The crucial structural point is T5. It does not say that θ ↦ δn(θ) is a step function; C3 shows that it is not. The source's equation (3) asserts the step-function characterisation, and that assertion is false for the source's own equation (1). T5 is the weaker true statement that survives: the infimum of the selection set is exactly αn.

Python layer

python/programme.py is importable without side effects and uses exact Fraction/sympy arithmetic. It provides:

  • alpha(n), alpha_scaled(n) — the harmonic angle and its π-normalised value;
  • greedy_digits(t, n_max), greedy_accumulated, residual — the exact digit recursion;
  • tree_intervals(n_max), thresholds_exact(n_max) — exact cylinder scan and thresholds;
  • tree_wavelets(n_max), reconstructed_wavelet(a,b), source_wavelet(a,b) — the repaired and source Haar wavelets;
  • haar_norm_sq, haar_mean, inner_product — exact integrals of piecewise-constant wavelets.
from fractions import Fraction
from python.programme import thresholds_exact, greedy_digits, tree_wavelets, haar_norm_sq

thresholds_exact(6)                    # [1/2, 1/3, 1/4, 1/5, 1/6, 1/7]
greedy_digits(Fraction(5, 12), 3)      # [0, 1, 0, 0]: 5π/12 is not θ_3*
all(haar_norm_sq(w) == 1 for w in tree_wavelets(5))

Run the suite from this folder:

python3 -m pytest -q tests

Recorded result: 8 passed in about 5 seconds. The suite includes the endpoint t = 0 and invalid-input edge cases.

Lean layer

lean/Topic.lean imports Mathlib, works in namespace HST, and proves T1–T7. It defines the harmonic angle, the residual-subtraction accumulator, the digit, and the two Haar coefficients. There is no sorry, axiom, or admit.

./lean/check.sh

The wrapper calls the shared checker at ../tools/check-lean.sh, which uses the local Mathlib installation (~/lean/mathlib4, Lean v4.35.0-rc2). The recorded build is lean/BUILD.log. See lean/README.md for what is and is not formalised, including the source's wavelet-normalisation and threshold corrections.
