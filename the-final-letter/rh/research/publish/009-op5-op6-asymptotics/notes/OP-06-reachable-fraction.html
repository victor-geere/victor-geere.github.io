OP-6 — The reachable fraction of the budget

A resolved open problem from the twin-prime-parity programme (research/twin-prime-parity), self-contained:
preliminaries, the census identity, the asymptotic law, verification, and the correction of the recorded guess.

Abstract

This note resolves OP-6 of the twin-prime-parity programme: the exact order of the reachable fraction of the budget, measure(S1)/P(p) → 0, where S1 is the writable set of the positive half-series ak = (2k)−p and P(p) = Σk≥1ak = 2−pζ(p) is its budget.

The register's recorded falsifiable form was a leading constant c in −log(measure/P) ~ c·p log p. The form is confirmed and the constant is c = 1 — not 1/ln 2 = 1.4427… and not 2/ln 2 = 2.8854…. The decay is p−p up to a linear exponential:

measure(S_1)/P(p) = p^(−p) · e^((1 + ln ln 2)·p) · (1 + o(1)) → 0 .

The method is a single substitution. The census identity of rh42 (Thm 10) gives measure(S1) = 2nmin−1Tnmin with Tn = 2−pζ(p,n); the 2−p cancels against the budget, leaving measure/P = 2nmin−1ζ(p,nmin)/ζ(p). At the threshold nmin(p) = p/ln 2 − 3/2 + O(1) (OP-5) one has p ≫ n, so the Hurwitz tail collapses to its first term, ζ(p,n) = z(p)·n−p with z(p) → 2. That yields L(p) := −log(measure/P) = p log p − (1 + ln ln 2)p − c(e(p))/p + O(1/p²) with the closed-form, e-dependent c(e) = −((ln 2)²/2)(e² − e + 9/4) (see the correction above). The linear coefficient −(1 + ln ln 2) = −0.6334870794… is exact and is verified to ten figures against exact census values; the 1/p coefficient is closed form but not constant — it is c(e(p)) ∈ [−0.540510, −0.480453] (see the correction above).

Status. The order, the leading constant 1, and the linear constant −(1 + ln ln 2) are proved; the 1/p coefficient is numerical. Nothing here bears on the twin prime conjecture, the parity problem, or the Riemann hypothesis. The result closes the chain rh42 Thm 10 ⟶ OP-5 ⟶ OP-6.

1. Preliminaries

1.1 The positive half-series and its budget

Fix p > 0 and consider the positive half-series

a_k = (2k)^(−p) , k = 1, 2, 3, … , P(p) = Σ_{k≥1} a_k = 2^(−p)·ζ(p) .

This is the even-index sub-series of the signed alphabet of the programme: a sine is written from the even terms, and P(p) is the budget — the largest value that can be written with the positive half alone. Write also

T_n := Σ_{k≥n} a_k = 2^(−p)·ζ(p, n) , so that P(p) = T_1 ,

with ζ(s,q) = Σk≥0(q+k)−s the Hurwitz zeta function. The convention Tn = 2−pζ(p,n) is the one used throughout rh42 and is the one verified in §4.1.

1.2 The census identity

Brown's criterion says the sub-sums of a decreasing positive sequence fill [0,Σak] iff every an ≤ Tn+1. The programme's census theorem (rh42 Thm 10) identifies exactly which targets are writable below that threshold.

Census (rh42 Thm 10) Let nmin(p) be the first index at which the tail (ak)k≥n becomes complete. Then
S_1 = ⋃_{A ⊆ {1,…,n_min−1}} ( Σ_{k∈A} a_k + [0, T_{n_min}] ) , measure(S_1) = 2^(n_min(p) − 1) · T_{n_min(p)} = 2^(n_min(p) − 1 − p) · ζ(p, n_min(p)) .
Proved in rh42 (each incomplete level doubles the interval count, the pieces being disjoint because h(n) < 0 there); re-derived and verified here in §4.1.

1.3 What was recorded, and what was missing

The register row OP-6 asked for the exact order of measure(S1)/P(p) → 0, with the falsifiable form "a predicted leading constant c in −log(measure/P) ~ c·p log p". The obstruction recorded was that the ratio "is a ratio of an exponentially growing count and a doubly-exponentially small length; neither factor is controlled asymptotically".

Both factors became controlled when OP-5 supplied nmin(p) = p/ln 2 − 3/2 + O(1) — the exponent sitting in the count 2nmin−1. The remaining step, taken here, is to recognise that at that exponent the sum Tnmin is dominated by its first term.

2. The main theorem

Theorem Let ak = (2k)−p, P(p) = 2−pζ(p), and let L(p) = −log( measure(S1)/P(p) ). Then
L(p) = p log p − (1 + ln ln 2)·p − c(e(p)) / p + O(1/p²) (p → ∞) , c(e) = −((ln 2)²/2)(e² − e + 9/4) , e(p) = ⌈p/ln 2 − 5/2⌉ − (p/ln 2 − 5/2) ,
equivalently
measure(S_1)/P(p) = p^(−p)·e^((1 + ln ln 2)·p)·(1 + o(1)) → 0 .
The coefficient of p log p is exactly 1, and the coefficient of p is exactly −(1 + ln ln 2).
Corollary (the recorded form, settled) In the register's −log(measure/P) ~ c·p log p, the constant is c = 1. The candidates 1/ln 2 = 1.4427… and 2/ln 2 = 2.8854… are both excluded. A linear term −(1 + ln ln 2)p = −0.6334870794…p is present at the same order.

3. Proof

The whole argument is one cancellation and one regime identification.

3.1 Cancellation of the budget

The census identity and P(p) = 2−pζ(p) share the factor 2−p, so it cancels:

measure(S_1)/P(p) = 2^(n_min − 1) · ζ(p, n_min) / ζ(p) .

Writing n = nmin(p) and taking logarithms,

L(p) = −(n − 1)·ln 2 − log ζ(p, n) + log ζ(p) .

Since ζ(p) = 1 + O(2−p) as p → ∞, the last term is o(1) and may be dropped. The problem is now one quantity: −log ζ(p,n) at n = nmin(p).

3.2 The regime at the threshold

OP-5 gives the exact first order nmin(p) = p/ln 2 − 3/2 + O(1). Hence

n_min(p)/p → 1/ln 2 = 1.4426950408… < 2 ,

so p > n at the threshold — in fact p ≈ (ln 2)·n. This is the whole reason the tail is a single term below: the threshold is deep in the low-n regime.

3.3 The Hurwitz tail at p ≫ n

Lemma (single-term tail) Let z(p) := ζ(p,n)·np. Then
ζ(p, n) = n^(−p)·z(p) , z(p) = Σ_{j≥0} (1 + j/n)^(−p) = 2 + o(1) .
Consequently −log ζ(p,n) = p log n − ln 2 + o(1).

Proof. The ratio of consecutive summands of z(p) is

(1 + 1/n)^(−p) = exp( −p·log(1 + 1/n) ) = exp( −p/n + O(p/n²) ) .

By §3.2, p/n → ln 2, so the ratio tends to e−ln 2 = 1/2. The series therefore converges geometrically, and its first term is 1: z(p) = 1 + (1/2) + O(1/4) = 2 + o(1). Taking logarithms gives the stated form. ∎

Pitfall. The two 2's here are different objects and must not be conflated: the 2 in z(p) → 2 is the geometric ratio of the low-n tail, while the 2 in 2nmin−1 is the census doubling. The former contributes only an O(1) term (−ln 2); the latter is the dominant (ln 2)·n.

3.4 The leading orders give c = 1

Combine §3.1 and §3.3. With a = ln 2 and n = p/a − 3/2 + O(1):

−(n − 1)·a = −p + (5/2)·a + O(1) p·log n = p log p − p·log a − (3/2)·a + O(1) −log z(p) = − log 2 + o(1)

Adding, the terms linear in p give −p − p·log a = −(1 + log a)p, so

L(p) = p log p − (1 + ln ln 2)·p + O(1) .

The coefficient of p log p is exactly 1, and the linear coefficient is −(1 + ln ln 2) because log a = ln(ln 2). Numerically 1 + ln ln 2 = 0.3665129205816643…, so the linear coefficient is −0.6334870794183357….

This is the recorded constant. The register's form −log(measure/P) ~ c·p log p has c = 1. Neither 1/ln 2 (the reciprocal of the n-to-p slope of OP-5) nor 2/ln 2 (twice it) appears — the latter would be the answer if the 2 of the census count were missing from the balance.

3.5 The 1/p term

Carrying the next order of log(n/(p/a)),

p log n = p log p − p log a − (3/2)a − 9a²/(8p) + O(1/p²) ,

Writing the true index as n = p/a − 3/2 + e with a = ln 2, the a·e terms cancel exactly and the net coefficient is the closed form

L(p) = p log p − (1 + ln ln 2)p − c(e(p)) / p + O(1/p²) , c(e) = −((ln 2)²/2)(e² − e + 9/4) .

The coefficient is closed form but not constant: it is the function c(e(p)) of the ceiling error, ranging over [−(ln 2)², −(9/8)(ln 2)²] = [−0.480453013918201, −0.540509640657977]. The constant −0.540509640658… is the e = 0 value only.

5. Why c·p log p alone is a weak diagnostic

Because the linear term is of the same order as the leading term, the ratio L/(p log p) converges to 1 only logarithmically slowly:

L(p)/(p log p) = 1 − (1 + ln ln 2)/log p + O(1/log² p) .

At p = 10⁶ it still reads 0.954; at p = 10³, 0.908. A one-parameter fit c·p log p to data in this range would understate c unless the linear term is carried. This is the quantitative form of the register's warning that "the two-sided bounds may be too lossy to pin a constant": here the loss is not in the bounds but in the functional form.

Appendix A — reproducible script

Run with an mpmath-enabled Python, e.g. /opt/homebrew/Caskroom/miniforge/base/bin/python3 op06_reachable_fraction.py. The file is stored beside this document as research/twin-prime-parity/open/op06_reachable_fraction.py.

#!/usr/bin/env python3
# OP-6: measure(S_1)/P(p) = p^-p e^((1+ln ln2)p)(1+o(1)) -> 0.
#   L(p) = -log(measure/P) = p log p - (1+ln ln2)p - 0.540509640658.../p + O(1/p^2).
# Reproduces: census cross-check vs rh42, leading coefficient 1,
#             linear coefficient -(1+ln ln2), 1/p coefficient.
import mpmath as mp
import numpy as np

mp.mp.dps = 80
a = mp.log(2)                          # ln 2
c2 = -(1 + mp.log(a))                  # -(1 + ln ln 2)
c3 = mp.mpf("-0.540509640658")          # historical smooth-index (e=0) value

def hzeta(s, a0):
    # zeta(s,a0); direct sum for s > 4 (geometric decay), mpmath otherwise
    if s > 4:
        return mp.fsum([mp.power(a0 + k, -s) for k in range(0, 500)])
    return mp.zeta(s, a0)

def nmin_exact(p):
    # first n with 2^-p(zeta(p,n+1) - n^-p) >= 0
    p = mp.mpf(p)
    n = max(2, int(p / a) - 3)
    while (2 ** -p) * hzeta(p, n + 1) - (2 * n) ** -p >= 0: n -= 1
    n += 1
    while (2 ** -p) * hzeta(p, n + 1) - (2 * n) ** -p < 0: n += 1
    return n

def census_exact(p):
    # T_n = 2^-p zeta(p,n)  =>  measure = 2^(n_min-1-p) zeta(p,n_min)
    p = mp.mpf(p); n = nmin_exact(p)
    T = (2 ** -p) * hzeta(p, n)
    Pp = (2 ** -p) * hzeta(p, 1)
    return n, mp.power(2, n - 1) * T, Pp, -mp.log(mp.power(2, n - 1) * T / Pp)

def L_asym(p):
    # p >> 1: L = -(n-1)ln2 + p ln n - ln z(p),  z(p) = zeta(p,n) n^p -> 2
    p = mp.mpf(p); n = p / a - mp.mpf(3) / 2
    zp = mp.fsum([mp.power(n + k, -p) for k in range(0, 500)]) * mp.power(n, p)
    return -(n - 1) * mp.log(2) + p * mp.log(n) - mp.log(zp)

# 1. exact census values and the rh42 cross-check
for p in [2, 3, 4, 6, 8, 10, 12]:
    n, m, Pp, L = census_exact(p)
    print(p, n, mp.nstr(m / Pp, 12))

# 2. the law on exact data
for p in [10**3, 10**4, 10**5, 10**6]:
    _, _, _, L = census_exact(p)
    print(p, mp.nstr((L - p * mp.log(p)) / p, 12))

# 3. the 1/p coefficient from the large-p branch
for p in [10**6, 10**9, 10**12, 10**13]:
    pm = mp.mpf(p); L = L_asym(pm)
    print(p, mp.nstr((L - pm * mp.log(pm) - c2 * pm) * pm, 12))
