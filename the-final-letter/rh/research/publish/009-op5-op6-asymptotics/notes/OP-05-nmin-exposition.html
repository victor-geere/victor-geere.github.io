OP-5 — The asymptotic of nmin(p)

A resolved open problem from the twin-prime-parity programme (research/twin-prime-parity), self-contained:
preliminaries, definitions, lemmas with proofs, the main theorem, verification, and the correction of the recorded guess.

Abstract

This note resolves OP-5 of the twin-prime-parity programme: the asymptotic behaviour, as p → ∞, of nmin(p) = min{ n : ζ(p, n+1) ≥ n−p }, the first index at which the tail of the p-series alphabet becomes a complete sequence in the sense of Brown.

The guess recorded in the programme, nmin(p) ≈ p + O(1), is false. The correct law is nmin(p) = p/ln 2 − 3/2 + O(1), and the underlying threshold sequence has the fully explicit second-order expansion Pn = (n + 3/2)ln 2 + c/n + O(1/n²) with c = 3(ln 2)² − (25/12)ln 2 = −0.00269758441194845395….

The method is a single asymptotic expansion of the boundary equation Φp(n) = Σj≥1(1 + j/n)−p = 1, taken along p = a n + g. The leading sum Σj≥12−j = 1 forces a = ln 2; vanishing of the 1/n coefficient forces g = (3/2)ln 2; the 1/n² coefficient, evaluated against the moments Sm = Σ jm2−j, gives c in closed form. Every constant is verified independently to ten significant figures against thresholds computed at 40–60 decimal digits, and the n = 1 member of the family reproduces the programme's own constant p* to 18 digits.

Status. The expansion and the two leading constants are proved; the value of c and the O(1/n²) remainder coefficient are numerical, stable over six decades. Nothing here bears on the twin prime conjecture, the parity problem, or the Riemann hypothesis; the result unblocks OP-6, an accounting question on the same family.

1. Preliminaries

1.1 The p-series alphabet and completeness

Fix a real parameter p > 1 and consider the decreasing positive sequence

a_k = k^(−p) , a_1 = 1 > a_2 > a_3 > … → 0 .

A classical completeness criterion of Brown for a decreasing sequence (ak) of positive terms with a1 = 1 states that every element of [0, Σk ak] is a subsum of the sequence if and only if

a_n ≤ Σ_{k>n} a_k for every n .

The quantity of interest is the first index at which the tail becomes complete. Define

h_p(n) := Σ_{k>n} k^(−p) − n^(−p) = ζ(p, n+1) − n^(−p) ,

where ζ(s,a) = Σk≥0 (k+a)−s is the Hurwitz zeta function, so that Σk>n k−p = ζ(p, n+1) exactly. Then

n_min(p) := min{ n : h_p(n) ≥ 0 } ,

and for n ≥ nmin(p) the tail (ak)k>n (once normed) is complete. The complement is an initial segment:

Inherited (rh42, §3, Thm 7–8) Unimodality. hp is unimodal in n with a single sign change, and { n : hp(n) < 0 } = {1, 2, …, nmin(p) − 1}. Hence nmin is well defined and the boundary is one equation.
This document uses that theorem; it does not reprove it. It was verified independently here (the sign of h straddles zero exactly once in every tested instance).

1.2 The normed boundary equation

Divide hp(n) ≥ 0 by the positive number n−p and substitute k = n + j:

h_p(n) ≥ 0 ⟺ Σ_{k>n} (k/n)^(−p) ≥ 1 ⟺ Σ_{j≥1} (1 + j/n)^(−p) ≥ 1 .

Write

Φ_p(n) := Σ_{j≥1} (1 + j/n)^(−p) .

Every summand is strictly increasing in n, so Φp is strictly increasing in n; and Φp is strictly decreasing in p. The boundary of the region {Φp(n) ≥ 1} is therefore a staircase.

Definition For each integer n ≥ 1 let Pn be the unique real number with

Φ_{P_n}(n) = 1 .

Then nmin(p) = n ⟺ Pn−1 < p ≤ Pn, and Pn is increasing in n.

Why the thresholds, not nmin itself. Because nmin takes integer values, the quantity nmin(p) − p/ln 2 never converges: it oscillates in a window of width 1 as p runs over the steps. The genuine asymptotic object — the one with a clean expansion — is the threshold sequence Pn.

1.3 The numbers Sm

Throughout, put x = 1/2 and

S_m := Σ_{j≥1} j^m x^j = Σ_{j≥1} j^m 2^(−j) ,

the moments of the geometric law with ratio 1/2. The values needed are

S_0 = Σ 2^(−j) = 1 , S_1 = Σ j 2^(−j) = 2 , S_2 = Σ j² 2^(−j) = 6 , S_3 = Σ j³ 2^(−j) = 26 , S_4 = Σ j⁴ 2^(−j) = 150 .

(Closed forms: Σj≥1 jmxj = Am(x)/(1−x)m+1 with the Eulerian polynomials; at x = 1/2 these give 1, 2, 6, 26, 150, …, the ordered Bell numbers.)

1.4 What the result is for

nmin is not an isolated curiosity: in the programme it is the exponent in the exact census law

measure(S_1) = 2^(n_min − 1) · T_{n_min} (rh42, Thm 10),

which governs the reachable fraction of the budget (register item OP-6). That ratio — an exponentially growing count against a doubly-exponentially small length — was unattackable while nmin itself was unknown. Its closed form is the missing input.

2. The main theorem

Theorem Let a = ln 2 and c = 3a2 − (25/12)a = 3(ln 2)2 − (25/12)ln 2. Then

(i) P_n = (n + 3/2)·a + c/n + O(1/n²) as n → ∞ , (ii) n_min(p) = p/a − 3/2 − c/p + O(1/p²) as p → ∞ ,

with the numerical value

c = 3(ln 2)² − (25/12)·ln 2 = −0.0026975844119484539513… .
Corollary (refutation of the recorded guess) The programme's recorded suggestion nmin(p) ≈ p + O(1) (rh42/truths.md:453) is false. The leading coefficient is 1/ln 2 = 1.442695040888963…, and nmin(p) − p is unbounded.

3. Proof

The whole argument is one asymptotic expansion of the single equation Φp(n) = 1, with p tied to n affinely. Everything is elementary; the only care required is in keeping the right number of terms (Lemma 3).

3.1 The exponent expansion

Lemma 1 (exponent expansion) Put p = a n + g with a, g = O(1). For fixed j ≥ 1 and u = j/n,
p·log(1 + j/n) = a j + C_1/n + C_2/n² + C_3/n³ + …
where
C_1 = g j − a j²/2 , C_2 = a j³/3 − g j²/2 , C_3 = −a j⁴/4 + g j³/3 .

Proof. log(1+u) = u − u²/2 + u³/3 − u⁴/4 + …, so

(an+g)·log(1+j/n) = (an+g)·[ j/n − j²/(2n²) + j³/(3n³) − j⁴/(4n⁴) + … ]

Multiplying out, the term with n−m receives a·(±) jm+1/(m+1) from an and g·(∓) jm/m from g. For m = 0: a j (the g-part is g j/n, which is order m = 1). Hence the displayed coefficients. ∎

Lemma 2 (the three leading terms of Φ) With x = e−a and the moments Sm,
Φ_p(n) = S_0 − (1/n) Σ_j x^j C_1 + (1/n²) Σ_j x^j ( C_1²/2 − C_2 ) + O(1/n³) .

Proof. By Lemma 1, (1+j/n)−p = exp(−p log(1+j/n)) = xj·exp(−C1/n − C2/n² − …). Expanding the exponential to second order, exp(−C1/n − C2/n²) = 1 − C1/n + (C1²/2 − C2)/n² + O(1/n³). Summing over j with weights xj gives the statement, since all moments Sm are finite. ∎

On the O(1/n³). The exponent expansion is not uniformly small in j: the coefficient of n−m in p·log(1+j/n) is a polynomial in j of degree m+1, so at j ~ √n the m=3 term is already O(1/n). What saves the bound is that the sum carries the weight xj = 2−j: the effective number of contributing indices is O(1), not √n, and the indices near √n enter with weight 2−√n. The remainder is therefore controlled by the finite moments S5, S6, … — genuinely O(1/n³). This point is the reason a naive "sum the error over √n terms" estimate gives the wrong answer.

3.2 The leading order fixes a = ln 2

Lemma 3 (leading order) At the threshold Φp(n) = 1 one must have S0 = Σj≥1 xj = 1, hence a = ln 2.

Proof. Φp(n) = S0 + O(1/n) by Lemma 2, so S0 = 1 to leading order. But Σj≥1xj = x/(1−x), which equals 1 exactly when x = 1/2, i.e. a = ln 2. ∎

With a = ln 2 we have x = 1/2 and therefore S0 = 1, so Φp(n) − 1 = O(1/n) and the threshold equation is now an equation for g.

3.3 The first correction fixes g = (3/2)ln 2

Lemma 4 (first correction) With a = ln 2,
Σ_{j≥1} x^j C_1 = g S_1 − (a/2) S_2 = 2g − 3a .
Hence the 1/n coefficient of Φp(n) − 1 vanishes if and only if g = (3/2)a = (3/2)ln 2.

Proof. C1 = gj − aj²/2, so ΣxjC1 = gΣj xj − (a/2)Σj²xj = gS1 − (a/2)S2. Insert S1 = 2, S2 = 6: = 2g − 3a, which vanishes iff g = 3a/2. ∎

Consequently Φp(n) = 1 + O(1/n²) already when p = an + (3/2)a, that is:

P_n = (n + 3/2)·ln 2 + O(1/n) . ← the leading law

In n-units the constant is 3/2; in p-units it is (3/2)ln 2 = 1.0397207708399179641…. These are the same statement about the same number of n's.

3.4 The second correction gives c

Lemma 5 (second correction) Let a = ln 2, g = 3a/2. Then
D_0 := Σ_{j≥1} x^j ( C_1²/2 − C_2 ) = 6a² − (25/6)a = −0.0053951688238969…
so that Φp(n) − 1 = D0/n² + O(1/n³) at p = an + 3a/2.

Proof. Insert g = 3a/2 into Lemma 1:

C_1 = (3a/2) j − a j²/2 = (a/2)·j(3 − j) C_2 = a j³/3 − (3a/2) j²/2 = a j³/3 − (3a/4) j²

Then

Σ x^j C_1²/2 = (a²/8) Σ x^j j²(j−3)² = (a²/8) [ S_4 − 6 S_3 + 9 S_2 ] = (a²/8) [ 150 − 156 + 54 ] = (a²/8)(48) = 6a² ,

and

− Σ x^j C_2 = − (a/3) S_3 + (3a/4) S_2 = − (26a/3) + (9a/2) = −(25/6) a .

Adding, D0 = 6a2 − (25/6)a. Numerically 6a2 = 2.8827180835092085… and (25/6)a = 2.8881132523331055…, giving D0 = −0.0053951688238969… ∎

Lemma 6 (threshold shift) Let p0 = an + 3a/2. The threshold p* = p0 + ε satisfies
ε = D_0/(2n) + O(1/n²) .

Proof. First-order Taylor in p at fixed n: 0 = Φp*(n) − 1 = (Φp0(n) − 1) + Φ′(p0)·ε + O(ε²). By Lemma 5 the first bracket is D0/n² + O(1/n³). For the derivative, differentiate the definition term by term:

Φ′(p) = Σ_j ( −log(1 + j/n) ) (1 + j/n)^(−p) = − (1/n) Σ_j j x^j ( 1 + O(1/n) ) = − S_1/n + O(1/n²) = − 2/n + O(1/n²) .

Substituting: 0 = D0/n² − (2/n)ε + O(1/n³) + O(ε/n²) + O(ε²), so ε = D0/(2n) + O(1/n²). ∎

Proof of the Theorem Part (i) follows from Lemmas 3, 4, 6 with
c = D_0/2 = 3a² − (25/12)a = 3(ln 2)² − (25/12)·ln 2 .
For part (ii), solve p = (n + 3/2)a + c/n for n. Write n = p/a − 3/2 + δ; then (n + 3/2)a = p + δa, so p = p + δa + c/n, giving δ = −c/(an) = −c/p + O(1/p²), i.e. nmin(p) = p/a − 3/2 − c/p + O(1/p²). ∎
Pitfall (the one genuine trap) Keep the g j²/2 term in C2. If one writes C2 = a j³/3 alone — dropping −g j²/2 — then ΣxjC2 = (a/3)S3 = 26a/3 = 6.0073… in place of the correct (25/6)a = 2.8881…, and D0 is inflated from −0.0054 to 6a² − 26a/3 = −3.1246 — a factor 579. That inflated value then predicts ε = −1.56/n, which the exact thresholds contradict by three orders of magnitude. The dropped term is not a small correction; it is the whole answer.
A second, purely bookkeeping trap: a constant quoted in p-units (3(ln2)/2 = 1.0397) and one quoted in n-units (3/2) describe the same law Pn = (n+3/2)ln2. Comparing them as if they disagreed invents a phantom failure of the method.

5. The exceptional set of the closed form

Because c < 0, each threshold sits slightly below the crossing point (n+3/2)ln 2. Consequently the ceiling form

n_min(p) = ⌈ p/ln 2 − 3/2 ⌉

is exact except on the union of intervals

p ∈ ⋃_n ( P_n , (n + 3/2)ln 2 ) , each of width (n+3/2)ln 2 − P_n = −c/n + O(1/n²) .

6. The n = 1 boundary

The n = 1 threshold solves Φp(1) = 1, i.e. Σk>1k−p = 1, i.e. ζ(p) = 2. That root is the programme's own constant p* = 1.7286472389981836….

Appendix A — reproducible script

Run with an mpmath-enabled Python, e.g. /opt/homebrew/Caskroom/miniforge/base/bin/python3 op05_nmin.py. The file is also stored beside this document as research/twin-prime-parity/open/op05_nmin.py.

#!/usr/bin/env python3
# OP-5: n_min(p) = p/ln2 - 3/2 + O(1);
#       P_n = (n + 3/2) ln 2 + c/n + O(1/n^2),  c = 3(ln2)^2 - (25/12) ln2.
# Reproduces: slope refutation, threshold law, O(1/n^2) bracket,
#             exceptional-set width, n = 1 boundary.
import mpmath as mp
import numpy as np

mp.mp.dps = 50
a = mp.log(2)
c = 3 * a ** 2 - mp.mpf(25) / 12 * a

def tail(n, p, M=400):
    # sum_{k>n} k^-p : ratio 2^-1 per step for large p, so M=400 is ample;
    # for small p use the exact Hurwitz zeta (the direct sum converges slowly).
    if p < 50:
        return mp.zeta(p, n + 1)
    return mp.fsum([mp.power(n + k, -p) for k in range(1, M + 1)])

def h(n, p):
    return tail(n, p) - mp.power(n, -p)

def P(n, halfwidth=None):
    # threshold by bisection (h is decreasing in p)
    P0 = (mp.mpf(n) + mp.mpf(3) / 2) * a + c / mp.mpf(n)
    w = halfwidth if halfwidth is not None else mp.mpf(1) / mp.mpf(n)
    lo, hi = P0 - w, P0 + w
    for _ in range(200):
        mid = (lo + hi) / 2
        if h(n, mid) < 0: hi = mid
        else:            lo = mid
    return (lo + hi) / 2

# 1. slope refutation
def nmin(p):
    n = 1
    while mp.zeta(mp.mpf(p), n + 1) < mp.power(n, -mp.mpf(p)): n += 1
    return n
for p in [10, 50, 200, 1000, 5000]:
    n = nmin(p); print(p, n, n / mp.mpf(p), n / (mp.mpf(p) / a))

# 2. threshold law + Richardson fit
rows = []
for n in [100, 500, 1000, 2000, 5000, 10000, 20000]:
    d = P(n) - (mp.mpf(n) + mp.mpf(3) / 2) * a
    rows.append((n, float(d * n)))
ns = np.array([r[0] for r in rows], float); ys = np.array([r[1] for r in rows])
A = np.vstack([np.ones_like(1 / ns), 1 / ns]).T
coef, *_ = np.linalg.lstsq(A[-4:], ys[-4:], rcond=None)
print("c_fit", coef[0], "c_pred", float(c), "diff", coef[0] - float(c))

# 3. O(1/n^2) bracket
for n in [10**3, 10**4, 10**5, 10**6]:
    P0 = (mp.mpf(n) + mp.mpf(3) / 2) * a + c / mp.mpf(n)
    off = abs(P(n) - P0)
    print(n, float(off), float(off * mp.mpf(n) ** 2))

# 4. exceptional set width
for n in [100, 1000, 10000]:
    P0 = (mp.mpf(n) + mp.mpf(3) / 2) * a
    lo, hi = P0 - mp.mpf(1) / n, P0
    for _ in range(120):
        mid = (lo + hi) / 2
        if h(n, mid) < 0: hi = mid
        else:            lo = mid
    print(n, float(P0 - (lo + hi) / 2), float(-c / n))

# 5. n = 1 boundary:  P_1 must equal the root of zeta(p) = 2
lo, hi = mp.mpf('1.5'), mp.mpf('2')
for _ in range(250):
    mid = (lo + hi) / 2
    if mp.zeta(mid) - 2 > 0: lo = mid
    else:                       hi = mid
print("root zeta=2", mp.nstr((lo + hi) / 2, 18))
print("P_1        ", mp.nstr(P(1, halfwidth=mp.mpf('0.5')), 18))
