Sieves for the von Mangoldt Function

Exact computation of Λ(n) for all n ≤ N, with proofs and certified checks.

First edition.   Subject class: 11Nxx (elementary and sieve methods), 11-04 (explicit calculations).   All algorithms below return exact data; every displayed value is accompanied by a check that can be re-run from the text.

Abstract

The von Mangoldt function Λ is the arithmetic function that is log p on the powers of a prime p and 0 elsewhere. It is the coefficient function of the logarithmic derivative of the Riemann zeta function, the increment of Chebyshev’s function ψ, and the weight on the prime side of the explicit formula. This note gives three elementary sieves that produce the entire table (Λ(1),…,Λ(N)) — a prime-power marking sieve, a divisor-sum sieve, and a Möbius-convolution sieve — with complete correctness proofs and complexity bounds. The divisor-sum sieve is also given in an integer form in which the primality of N(n) := n / ∏d|n, d<n exp Λ(d) is decided by integer arithmetic alone, logarithms being needed only to report the value. We prove the divisor identity ∑d|n Λ(d) = log n, its Möbius inversion Λ = μ * log, the identity ψ(x) = log lcm(1,…,⌊x⌋), and ψ(x) = ∑k≥1 θ(x1/k); we record a table of ψ(10k) for k ≤ 6 and verify the exact identities exp ψ(10) = 2520 = lcm(1,…,10) and exp ψ(20) = 232792560 = lcm(1,…,20).

Keywords: von Mangoldt function; von Mangoldt sieve; Chebyshev ψ and θ; Euler product; logarithmic derivative of ζ; Möbius inversion; linear sieve; additive functions; least common multiple.

1. Introduction

Let Λ : ℕ → ℝ be the function introduced by von Mangoldt [1] in his proof that Chebyshev’s function has the asymptotic behaviour predicted by the prime number theorem:

Λ(1) = 0,    Λ(n) = log p  if  n = pk (p prime, k ≥ 1),    Λ(n) = 0  otherwise.

Three properties make it ubiquitous. First, its summatory function is Chebyshev’s ψ, and ψ(x) ∼ x is equivalent to the prime number theorem [4, 5]. Second, it is the coefficient function of −ζ′/ζ: −ζ′(σ)/ζ(σ) = ∑n≥1 Λ(n) n−σ for σ > 1. Third, it weights the prime side of the explicit formula and of Chebyshev-type bounds [6, 7].

The practical problem addressed here is entirely elementary and completely solvable: produce the whole table Λ(1),…,Λ(N) exactly, and cheaply. Because Λ(n) is 0 or the logarithm of a prime, the table carries only integer information; only the final presentation as a real number involves a logarithm. We give three sieves and prove them correct:

  1. the prime-power marking sieve (§3.1), simplest and fastest;
  2. the divisor-sum sieve (§3.2), which needs no factoring and has an exact integer form;
  3. the Möbius-convolution sieve (§3.3), a direct realisation of Λ = μ * log.

Section 3.4 recalls the linear sieve for multiplicative functions and explains why it does not by itself cover Λ — a point that matters when choosing an implementation. Section 4 collects the exact identities that make each output checkable, and §5 lists the standard uses.

2. The function Λ and its identities

2.1 Support and elementary description

Proposition 2.1 (support). Λ(n) ≠ 0 if and only if n is a power of a prime. Moreover Λ(pk) = log p for every k ≥ 1: Λ is constant along the powers of each prime.

Proof. Immediate from the definition: the prime powers pk with p fixed have the same logarithm log p, and every n with at least two distinct prime divisors is assigned 0. □

2.2 The divisor identity and Möbius inversion

Proposition 2.2 (divisor identity). For every n ≥ 1,

∑d|n Λ(d) = log n.

Proof. For n = 1 both sides are 0. Let n = ∏i=1r piai be the prime factorization. A divisor d has Λ(d) ≠ 0 exactly when d = pij for some i and 1 ≤ j ≤ ai (Proposition 2.1), and then Λ(d) = log pi. Hence

∑d|n Λ(d) = ∑i=1r ∑j=1ai log pi = ∑i=1r ai log pi = log n. □

Proposition 2.2 says Λ * 1 = log, where * is Dirichlet convolution. Möbius inversion (μ * 1 = ε, the identity of the convolution algebra [5, Thm. 2.1]) turns it into an explicit formula.

Corollary 2.3. For every n ≥ 1,

Λ(n) = ∑d|n μ(d) log(n/d) = −∑d|n μ(d) log d,

that is, Λ = μ * log.

Proof. Convolve Λ = log * μ with 1; this is the Möbius inversion of Proposition 2.2. The second form uses ∑d|nμ(d) = 0 for n>1. □

2.3 Two structural remarks: Λ is neither additive nor multiplicative

Proposition 2.4. Λ is neither additive nor multiplicative.

Proof. At n = 6 = 2·3: Λ(6) = 0, whereas Λ(2) + Λ(3) = log 2 + log 3 = log 6 ≠ 0 and Λ(2)Λ(3) = (log 2)(log 3) ≠ 0. □

This is the structural reason why the algorithms below either mark prime powers directly or use the divisor identity: a recurrence that multiplies or adds values attached to the primes of n computes an additive or multiplicative function, and Λ is neither. The additive function that carries the same information on prime powers is worth naming.

Proposition 2.5 (the additive sibling). Let L(n) = log rad(n) = ∑p|n log p for n ≥ 1 (L(1) = 0). Then:

  1. L is additive on coprime arguments: L(mn) = L(m) + L(n) when gcd(m,n) = 1; it is the unique additive function with L(p) = log p;
  2. L and Λ agree exactly on the prime powers and on n = 1, and differ at every n with at least two distinct prime divisors;
  3. ∑n≤x L(n) = ∑p≤x log p · ⌊x/p⌋, whereas ψ(x) = ∑pk≤x log p.

Proof. (i) rad(mn) = rad(m)rad(n) for coprime m,n; an additive function is determined by its values on prime powers, and L(pk) = log p = L(p). (ii) If n = pk then rad(n) = p and L(n) = log p = Λ(n); if n has r ≥ 2 distinct prime divisors then Λ(n) = 0 while L(n) > 0. (iii) Exchange the order of summation: ∑n≤x∑p|nlog p = ∑p≤xlog p · #{n ≤ x : p | n} = ∑p≤xlog p · ⌊x/p⌋. □

Proposition 2.5 is a statement about two different functions and their exact domains of agreement; it is the reason the integer form of §3.2 tests an integer against 1 rather than testing an additive recurrence.

2.4 Chebyshev’s functions

Define ψ(x) = ∑n≤x Λ(n) and θ(x) = ∑p≤x log p.

Proposition 2.6. For every real x ≥ 1,

ψ(x) = ∑pk≤x log p = log lcm(1,2,…,⌊x⌋).

Proof. Every prime power pk ≤ x satisfies p ≤ ⌊x⌋, and pk ≤ ⌊x⌋ conversely. Hence ψ(x) = ∑p ≤ ⌊x⌋ (max{k : pk ≤ ⌊x⌋}) log p = log ∏p≤⌊x⌋ p⌊logp⌊x⌋⌋, and the last product is the least common multiple of 1,…,⌊x⌋. □

Proposition 2.7. For every x ≥ 1, ψ(x) = ∑k≥1 θ(x1/k), the sum being finite (all terms with k > log2 x vanish).

Proof. Group the prime powers in Proposition 2.6 by the exponent k: the k-th group is ∑p ≤ x1/k log p = θ(x1/k). □

2.5 The Dirichlet series

Proposition 2.8. For Re s > 1,

−ζ′(s)/ζ(s) = ∑n≥1 Λ(n) n−s.

Proof. Absolute convergence for Re s > 1 allows termwise differentiation of the Euler product. Taking logarithms, log ζ(s) = ∑p −log(1 − p−s) = ∑p∑k≥1 p−ks/k, and differentiating gives −ζ′(s)/ζ(s) = ∑p∑k≥1 (log p) p−ks = ∑n≥1Λ(n)n−s. □

3. Three exact sieves

Throughout, N ≥ 2 is the table bound and log denotes the natural logarithm. Each algorithm fills an array lam[1..N]. We prove each one returns lam[n] = Λ(n) for every n.

3.1 The prime-power marking sieve

The definition of Λ is a recipe: enumerate the primes, and for each prime mark its powers. Primality is obtained from the ordinary sieve of Eratosthenes. 

def von_mangoldt(N):
    lam  = [0.0] * (N + 1)          # lam[n] will hold Lambda(n)
    is_p = [True] * (N + 1)         # Eratosthenes table
    for p in range(2, N + 1):
        if is_p[p]:
            pk = p
            while pk <= N:          # mark p, p^2, p^3, ... 
                lam[pk] = log(p)    # Lambda(p^k) = log p
                pk *= p
            for m in range(p * p, N + 1, p):
                is_p[m] = False
    return lam

Theorem 3.1 (correctness of Algorithm A). The array returned by von_mangoldt(N) satisfies lam[n] = Λ(n) for all 1 ≤ n ≤ N.

Proof. The inner assignments write only at indices of the form pk, so lam[n] is changed only if n is a prime power, and then it is set to log p. It remains to see that every prime power is written exactly once, and with the correct value. Let n = qk. Since is_p[q] is true when the outer loop reaches q (the Eratosthenes table is correct), the while loop writes lam[qk] = log q. If also n = rj with r ≠ q prime, then n would have the two distinct prime divisors q, r, contradicting n = qk. Hence each prime power is written once, with the value required by the definition. □

Complexity. The primality sieve costs O(N log log N) operations and O(N) bits. The marking loop runs once per prime power ≤ N; their number is π(N) + π(N1/2) + … = O(N/log N). Total time O(N log log N), memory O(N) (or O(N/log N) bits for the prime table if lam is stored separately).

3.2 The divisor-sum sieve

A factoring-free alternative follows from Proposition 2.2. Process n = 1,2,3,… in increasing order, keeping a running array acc[n] = ∑d|n, d<n Λ(d). At step n the value Λ(n) is log n − acc[n], after which it is distributed to the multiples of n. 

def von_mangoldt_divisor(N):
    lam = [0.0] * (N + 1)
    acc = [0.0] * (N + 1)           # acc[n] = sum_{d|n, d

Theorem 3.2 (correctness of Algorithm B). For all 1 ≤ n ≤ N, lam[n] = Λ(n).

Proof. By strong induction on n. For n = 1, acc[1] = 0 and lam[1] = log 1 = 0. For n ≥ 2, assume the claim for all d < n. Every proper divisor d of n is < n, and at its own step it added Λ(d) to acc[n]; no other contribution is made. Hence acc[n] = ∑d|n, d<n Λ(d), and Proposition 2.2 gives log n − acc[n] = ∑d|nΛ(d) − ∑d|n,d<nΛ(d) = Λ(n). □

Complexity. The inner loop makes ∑n≤N(⌊N/n⌋ − 1) = O(N log N) additions, and no multiplications; memory O(N).

The integer form of the divisor-sum sieve

Algorithm B can be carried out in exact integer arithmetic. Exponentiate Proposition 2.2:

∏d|n exp Λ(d) = n,    hence    exp Λ(n) = n / P(n),    P(n) := ∏d|n, d<n exp Λ(d).

Since exp Λ(d) is 1 or a prime, P(n) is a positive integer and the quotient N(n) := n/P(n) is an integer by Proposition 2.2. The next statement identifies it; its content is that no logarithm and no primality test are needed to detect whether Λ(n) vanishes.

Theorem 3.3 (integer detection of prime powers). For every n ≥ 1,

N(n) = n / P(n) = { 1, if n is not a prime power;   p, if n = pk is a prime power. }

Consequently Λ(n) = 0 if N(n) = 1, and Λ(n) = log N(n) otherwise, with N(n) prime in that case.

Proof. By Proposition 2.2, P(n) = n/expΛ(n). If n = pk then expΛ(n) = p and N(n) = p. If n is not a prime power then expΛ(n) = 1 and N(n) = n. (Equivalently, every divisor d < n contributing a nontrivial factor to P(n) is itself a prime power pj, and the total p-adic valuation of P(n) is vp(n) when some other prime divides n, and vp(n) − 1 when n = pk.) □

def von_mangoldt_integer(N):
    # exact: P[n] is an integer, N(n) = n // P[n] is 1 or a prime
    P   = [1] * (N + 1)             # P[n] = prod_{d|n, d<n} exp(Lambda(d))
    lam = [0.0] * (N + 1)
    for n in range(2, N + 1):
        q = n // P[n]               # integer division; divides exactly
        if q != 1:                  # q is prime
            lam[n] = log(q)
        for m in range(2 * n, N + 1, n):
            P[m] *= q               # q = exp(Lambda(n)); q = 1 is a no-op
    return lam

Example. P(2)=P(3)=1, so N(2)=2, N(3)=3 and Λ(2)=log 2, Λ(3)=log 3. Then P(6)=2·3=6, so N(6)=1 and Λ(6)=0; while P(4)=2, so N(4)=2 and Λ(4)=log 2. The integer N(n) always fits in [1,n], so all updates are exact in machine integers for N below the word-size limit, and in arbitrary precision beyond it.

3.3 The Möbius-convolution sieve

Corollary 2.3 offers a third route: sieve the Möbius function μ (which is multiplicative) and sum. 

def von_mangoldt_moebius(N):
    mu    = [0] * (N + 1); mu[1] = 1
    primes, comp = [], [False] * (N + 1)
    for i in range(2, N + 1):                    # linear sieve for mu
        if not comp[i]:
            primes.append(i); mu[i] = -1
        for p in primes:
            if i * p > N: break
            comp[i * p] = True
            if i % p == 0:
                mu[i * p] = 0                    # p^2 | i*p
                break
            mu[i * p] = -mu[i]
    lam = [0.0] * (N + 1)
    for d in range(1, N + 1):                    # Lambda = mu * log
        if mu[d] != 0:
            for m in range(d, N + 1, d):
                lam[m] += mu[d] * log(m // d)
    return lam

Proposition 3.4. The returned array satisfies lam[n] = Λ(n) for all n ≤ N.

Proof. The linear sieve returns the Möbius function [8]; the double loop accumulates ∑d|nμ(d)log(n/d), which is Λ(n) by Corollary 2.3. □

Complexity. The sieve is O(N); the convolution is ∑d≤NN/d = O(N log N) operations. This route uses real logarithms of integers inside the convolution; for exact output it should be run in a symbolic or sufficiently precise arithmetic, or replaced by Algorithm B′ above, whose decisions are integral.

3.4 Why the linear sieve for multiplicative functions does not cover Λ

For comparison, the standard linear sieve computes any multiplicative function f from its values on prime powers: with p the smallest prime factor of i·p, one uses f(ip) = f(i)f(p) when p ∤ i, and a separate rule involving f(pk) when p | i [8]. Multiplicativity is exactly what makes the recurrence close, and it is exactly what Λ lacks (Proposition 2.4). The same applies to additive functions: their linear-sieve recurrence closes because additivity ties the value at ip to the values at i and p. Λ is therefore outside both families, which is why one either marks prime powers (Algorithm A) or uses the divisor identity (Algorithms B and C). The additive function that is inside the additive family is L = log rad of Proposition 2.5; it is computed by the additive recurrence with f(pk) = log p, and it agrees with Λ exactly on the prime powers.

4. Exactness and checks

4.1 What is exact

Algorithms A and B′ test primality and divisibility by integer arithmetic. Their decisions — whether Λ(n) vanishes — are therefore exact; only the reporting of the nonzero value uses log. Algorithm B in its real form computes log n − acc[n]; the subtraction is a difference of logarithms of integers, so it is exact whenever the arithmetic used for logs is symbolic, and is accurate to the working precision otherwise.

4.2 Two identities that certify the table

The table can be checked without external data.

  1. Per-index check (divisor identity). For every n ≤ N, verify ∑d|n Λ(d) = log n. Since each nonzero term is log p, the check is equivalent to the exact integer statement ∏d|n, Λ(d)≠0 expΛ(d) = n, which can be tested with integer arithmetic alone using the integer form of §3.2.
  2. Sieve-against-sieve check. Run Algorithm A and the integer form of Algorithm B and compare the decisions (zero or nonzero) and the primes reported. Agreement over 1 ≤ n ≤ N is a complete check of the table.

4.3 Chebyshev’s function

Summing the table gives ψ(x). Proposition 2.6 predicts the exact value ψ(x) = log lcm(1,…,⌊x⌋). Table 1 lists ψ(10k), computed by Algorithm A; the last two entries illustrate the sieve scale.

5. Applications

5.1 Chebyshev’s bounds and the prime number theorem

The elementary estimates c1x ≤ ψ(x) ≤ c2x and θ(x) ≤ c x are obtained by partial summation from Chebyshev’s function [4, 5, 7]; with Table 1 one can calibrate them. The equivalence ψ(x) ∼ x ⇔ π(x) ∼ x/log x is the prime number theorem, proved by Hadamard and de la Vallée Poussin and by several elementary routes [4, 5, 10].

5.2 The Euler product and the explicit formula

Proposition 2.8 identifies the table with the coefficients of −ζ′/ζ. In the explicit formula, the prime side is

∑n≥2 (Λ(n)/√n) (g(log n) + g(−log n))

for an even test function g; the table supplies every coefficient Λ(n) exactly, and partial summation with Chebyshev’s bound ψ(x) ≤ (log 4 + 4)x [7] controls the truncation. The same table gives Mertens-type sums by grouping on the sign of μ.

5.3 Least common multiples and binomial coefficients

Proposition 2.6 reads lcm(1,…,n) = exp ψ(n), so the sieve also computes the least common multiple table. This is the starting point for the classical estimates of lcm(1,…,n) and of the denominators of binomial coefficients [3, §22].

5.4 Normal order of additive functions

The additive sibling L = log rad of Proposition 2.5 satisfies L(n) = ∑p|nlog p; the distribution of such sums over n ≤ x is the Erdős–Kac circle of ideas [9], and the exact identity of Proposition 2.5(iii) is the first term in that analysis.

For a single table the prime-power marking sieve (Algorithm A) is the method of choice: it is shortest, fastest, and its decisions are integral. The divisor-sum sieve is preferable when the implementation should avoid a factorization table entirely, or when Λ is wanted one value at a time: Algorithm B′ computes Λ(n) from P(n), an integer in [1,n], with the test P(n) < n ⇔ n is a prime power. All three methods are certified by the divisor identity of Proposition 2.2, which is the single mathematical fact underlying the computation.
