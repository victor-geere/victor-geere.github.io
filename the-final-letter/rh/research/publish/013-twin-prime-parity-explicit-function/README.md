## The three objectives

- **O3 — the η/Euler route** gives a fast, self-contained evaluator of `ζ` on the
  critical line (`η = (1−2^(1−s))ζ` + Euler's transformation); it is an *evaluator*,
  not a certification.
- **O1 — the Dirichlet generalisation** gives the certification machinery for Dirichlet
  `L`-functions: the Route A/B/C theorem cores are general in Lean, the
  Riemann–von Mangoldt interface is a compiled conditional theorem from `(hL, hH)`, and
  the sharp archimedean rate `‖Γ(σ+it)‖ ≤ 2√(2π)|t|^(σ−1/2)e^(−(π/2)|t|)` is
  mathematically complete and verified.
- **O2 — the decomposition-lab verdict** settles that the harmonic tier cannot see
  zeros — a negative result recorded so it is not re-attempted.

Final tally: **19 done · 3 refuted · 3 blocked · 2 open** across 27 tasks.

## What is proved

The 11-item ledger (see [`truths.md`](truths.md) for the full table with links):

1. Greedy digit word (Rh41) — factor-complexity law, inverse-problem impossibility.
2. Signed Tau alphabet (Rh42) — budget algebra, Brown's criterion, census law, four thresholds, parity lock.
3. Balance `⇔ Re S_N(t) = 0` (Rh43).
4. Smoothing does not remove `√N`; only the functional equation does (Rh044).
5. Weil explicit formula + Turing windows `1/2 < Im < 15`, `1/2 < Im < 33` (Rh45/010), unconditional.
6. Finite-prefix indeterminacy (two-point Chowla) (Rh46).
7. Sylvester-sparsity for the greedy support (Rh47).
8. OP-5/OP-6 asymptotics (Op56).
9. von Mangoldt sieves (sibling `publish/001`).
10. Three thresholds `pN < pP < p*` (TppLean).
11. 011 part (A) steps 1–3 (Dirichlet instantiation).

Plus the **sharp archimedean rate** — mathematically complete and verified (sup ratio
0.559); the Lean formalisation is one lemma (the Euler–Maclaurin endpoint term) short.

**Not done:** nothing is proved about twin primes or the parity obstruction —
`Σ_{n≤x} λ(n)λ(n+2) = o(x)` remains OPEN.

## Running the checks

```sh
cd lean && ./check.sh --all                          # 97 modules, Lean 4 + Mathlib
cd python && python3 t12_sharp_rate_probe.py         # the sharp rate (exit 0)
cd python && python3 -c "import ivmath, eta_interval, dirichlet_interval"   # engine import
python3 verify_objectives.py                         # the registry gate (RESULT: OK)
```

External prerequisites: the **Lean 4** toolchain (`leanprover/lean4:v4.35.0-rc2`) and
**Mathlib** at `$LEAN_PREFIX/mathlib4` (default `$HOME/lean/mathlib4`), plus **Python 3**
with `mpmath`/`numpy`/`sympy`. `.olean` and `__pycache__` are not shipped; they are
regenerated by the builds above.
