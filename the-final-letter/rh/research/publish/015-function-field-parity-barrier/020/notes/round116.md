## 1. The envisioned path

Round 113 found that `T(n;h)` is constant on the classes generated by `h ↦ a^n h` and `h ↦ −h`, and that the
scaling law and the even symmetry (both proved in 018) explain those classes. The natural sharpening is a
*counting* prediction, independent of any twin data:

```
#distinct values of T(n; ·) on 𝔽_q^×  =  #orbits of ⟨ (𝔽_q^×)^n , −1 ⟩ acting on 𝔽_q^× .
```

If the observed number of distinct values equals the orbit count, then the finite-`n` shift dependence is
*entirely* explained by the two symmetries, with no extra coincidences. That is a sharp, falsifiable structural
statement, and it is cheap to test across several `q`.

## 2. Wild guess 57

> **Wild guess 57.** The number of distinct values of `T(n;h)` over `h ∈ 𝔽_q^×` equals the number of
> `⟨(𝔽_q^×)^n, −1⟩`-orbits, exactly — no accidental coincidences between orbits.

**Why guess it.** The two symmetries are proved, so the orbit count is an upper bound on the number of distinct
values. The guess is that nothing else collapses.

**Falsification test.** Compute `T(n;h)` for all `h`, count distinct values, and compare with the orbit count
`g` if `(q−1)/g` is even and `g/2` otherwise, where `g = gcd(n, q−1)`.

## 3. Results

```
#orbits = g        if k even,
        = g/2      if k odd.
```

This closes the last open structural question of the phase: every feature of the finite-`n` data is now
accounted for by a proved symmetry or by the main term plus its Weil-scale error.

## 4. Phase 020 — synthesis

Ten rounds produced the following picture. Over `𝔽_q[x]`, with `S(q)` the twin singular series:

| result | statement | round |
|---|---|---|
| main term | `T(n) = S(q)q^n/n² + E(n)`, `|E|/q^{n/2} ∈ [0.008, 0.30]` for `n ≤ 14` | 109, 115 |
| not spectral | `T(n)` satisfies no finite linear recurrence | 107 |
| exact expansion | `T(n) = Σ_{d,e} μ(d)μ(e) C(d,e)`, boundary included | 108 |
| divergent truncation | the `k ≤ n` part is a partial product of a divergent product; boundary cancels it | 108 |
| grading | `y = n/2` is exact by the degree inequality; formalised | 108, 111 |
| sieve cap | `Λ²` at level `n/2` is exactly `4×` the truth (asymptotically) | 110, 112 |
| bilinear dead | the pair weight is indefinite; no bound | 111 |
| windows | no `L^{−1/2}` cancellation; error is deterministic | 112 |
| large sieve | slack of order `n`; bound `≍ q^n/n` vs main `q^n/n²` | 114 |
| shift law | `T(n;h)` is exactly the orbit decomposition of `𝔽_q^×` | 113, 116 |

**The barrier, stated once.** Four independent mechanisms — `Λ²`, bilinear weights, degree windows, the large
sieve — each fail by a computable factor (`4`, undefined, position-dependent, `n`). They fail for the same
structural reason: none of them can resolve the two local conditions *jointly* and *exactly*. What does is
two-dimensional equidistribution of the pair `(f, f+2)`, which over `𝔽_q[x]` is supplied by the Frobenius and
over `ℤ` is the twin prime conjecture itself.

**The transfer demand.** A proof over `ℤ` needs a **grading substitute**: a canonical, error-controlled
truncation of the Möbius sum `1_Irr = Σ μ`. Over `𝔽_q[x]` the degree provides it (`deg d ≤ n`), with the error
localised in the boundary stratum. Over `ℤ` the sum runs over all divisors with no canonical cut, and the error
*is* the two-point Chowla correlation.

**What was proved, as opposed to measured.** Proved: the grading lemma, the boundary `0/1` lemma, the local
factors `2^k`, the shift-independence of the singular series, the linear base case, `T(1) = q`. Measured: every
constant above (`4`, the error ratios, the orbit counts, the large-sieve slack). The measurements are exact
computations on finite ranges; they are not proofs of asymptotic statements.

## 5. Lean

`Orbit.ne_neg_self` and `card_orbit`: in odd characteristic a nonzero shift is not its own negative, so the
`h ~ −h` orbits have size two. This is the second half of the orbit law; the first half is the 018 scaling law.
