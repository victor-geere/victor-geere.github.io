## 0. The object and the conventions (re-derived, not inherited)

The survey is worked out in two notational systems. Both were re-derived here
from the digit rule and checked in exact `Fraction` arithmetic
(`lib/tpp_no_limit_orbit.py`, `check_identities`).

**System A** (`digitword.py`, `probes.py`, `K_remaining.md`): the greedy rule
subtracts `1/n_k` with `n_k = ⌈1/r_k⌉`, i.e.

```
r_{k+1} = r_k - 1/n_k,     n_k = ceil(1/r_k),
s_k     = 1 - {1/r_k} = 1 - f_k,      c_k := r_{k+1}/r_k^2.
```

**System B** (the task statement and `research/open-tractability.md`): the
"augmented" digit is `q_k = n_k - 2`, i.e. `r_{k+1} = r_k - 1/(q_k+2)`.

The two are the same orbit; the dictionary is `n_k = q_k + 2`,
`u_k = 1/r_k = q_k + 2 - s_k`, i.e. `s_k = q_k + 2 - u_k`.

### 0.1 The squaring law: the survey's identity is CORRECT

> **(S) PROVED.** For every step with `r_{k+1} > 0`,
> `c_k = r_{k+1}/r_k^2 = s_k/(1 + s_k r_k)`.

*Proof.* With `u = 1/r_k` and `n = n_k = ceil(u)`, write `f = {u} = u - (n-1)`,
so `u = n - 1 + f` and `s_k = 1 - f = n - u`. Hence `r_k = 1/u = 1/(n-1+f)` and

```
r_{k+1} = r_k - 1/n = 1/(n-1+f) - 1/n = (1-f)/(n(n-1+f)) = s_k r_k / n.
```

Therefore `c_k = r_{k+1}/r_k^2 = (s_k r_k/n) u^2 = s_k u/n = s_k/(n r_k)`.
On the other hand `1 + s_k r_k = 1 + (n-u)/u = n/u = n r_k`, so
`s_k/(1+s_k r_k) = s_k/(n r_k) = c_k`. `qed`

Verified exactly (max deviation **0**) on 351 rational seeds; the identity
requires `r_{k+1} > 0` (at the exact rational termination `r_k = 1/n`,
`c_k = 0` while `s_k/(1+s_k r_k) > 0`, so that single degenerate step must be
excluded — the survey's phrasing omits this).

### 0.2 The backward prescription

In System A the *exact* forward `u`-map is `u_{k+1} = n_k u_k/(n_k - u_k)`
(equivalently `u_{k+1} = q_k^2/s_k - q_k + 1`), and its **exact inverse** is

```
u_k = n_k u_{k+1}/(n_k + u_{k+1}).                                        (B)
```

Verified exactly (0 deviation, 1818/1818 random admissible steps). The
`q`-forward form used by the survey, `q_{k+1} ≈ q_k^2/α_k`, corresponds under
`u_k = q_k + 2 - s_k` to the *self-consistent* target
`α_k = (q_k^2 + 2q_k)/q_{k+1}`, and then `s_k = α_k + O(1/q_k)`. So the
survey's claim `q_{k+1} = ⌊q_k^2/α_k⌋`, `s_k ≈ α_k` is **correct to leading
order**, with the corrected constant (`+2q_k`) needed for the exact statement.
This is the sense in which the lead is confirmed; everything below is stated in
System A, with the exact inverse (B) doing the work.

## 1. OP-28 = OP-30 — a family of `x` whose orbit average has no limit

### 1.1 Verdict

**PROVED** (constructive). The survey's lead is right; the two missing steps it
named (realisability of the prescribed word, uniformity of the error) are done
below.

### 1.2 The construction

Fix `q_0 = 8` (any `q_0 ≥ 2`, chosen `≥ 8` to make the first-order error
tiny). Let `(M_j)_{j≥0}` be a strictly increasing sequence of block lengths with
`M_j ≥ 3 M_{j-1}` and `M_0 ≥ 1`; the concrete choice below is `M_j = 3^j`
(any geometric sequence with ratio `r ≥ 3` works, and the difference of the two
block means is `(1 - 1/r)|log 2| ≥ (2/3)log 2 = 0.4621`). Put

```
α_k = 1/2   if S_j <= k < S_{j+1} with j even,      S_j := M_0 + ... + M_{j-1},
α_k = 1/4   if S_j <= k < S_{j+1} with j odd.
```

The prescribed word is built **backwards** from a terminal state (this is the
realisability constraint: the tail determines the head):

```
q_N  chosen huge,      u_N := q_N + 1 + 1/2,       (i.e. r_N in the cell of q_N)
u_k  := n_k u_{k+1}/(n_k + u_{k+1})   backwards,   n_k := q_k + 2,       (1)
q_k  := ceil(u_k) - 2.
```

Define

```
x := sum_{k>=1} 1/(q_k + 2).
```

### 1.3 The theorems

> **Theorem 1 (realisability — PROVED).** Let `(q_k)` be the backward sequence
> (1) and `x = Σ_{k≥1} 1/(q_k+2)`. Then the greedy orbit of `x` has
> `n_k = q_k + 2` for every `k ≥ 1`, i.e. `q_k = ⌈1/r_k⌉ - 2` for all `k ≥ 1`.
>
> *Proof.* `x = 1/(q_1+2) + tail` with `0 < tail < 2/q_2`. Hence
> `1/x = (q_1+2)/(1 + (q_1+2)·tail)` lies in `(q_1+1, q_1+2)`, so
> `⌈1/x⌉ = q_1+2` and the first digit is `n_0 = q_1+2`; the residual after it is
> `r_1 = (1/(q_2+2) + ...) / (1 + (q_1+2)tail)` which equals `1/u_1` exactly by
> (1), and induction repeats the argument. ∎

*Exact-rational machine check:* for the short case `α = 1/2,1/4,1/2,1/4` the
construction gives the exact rational seed
`x = 300129656263973531720568953662090234/48845289055200132283765298144075427525`
and the forward greedy orbit reproduces `q_1,q_2,q_3,q_4` **exactly**
(§A: "prescribed word … realised: True"; and §C(C0) for the self-consistent
word). This is the survey's missing step (i).

> **Theorem 2 (error control — PROVED).** With `α_k` the realised value
> `α_k = (q_k^2 + 2q_k)/q_{k+1}` and `δ_k := |s_k - α_k|`,
> `Σ_{k≥0} |log s_k - log α_k| ≤ 2 Σ_k δ_k ≤ B`, where `B` is an explicitly
> computable rational, `B ≤ 1.6·10^{-3}` for `q_0 = 8`. Moreover
> `Σ_{k≥0} |log c_k - log s_k| ≤ Σ_k r_k ≤ 2/q_1 < 10^{-2}`.
>
> *Proof.* The backward map `ψ_k(y) = (q_k+2)y/(q_k+2+y)` is strictly
> increasing with `ψ_k'(y) = ((q_k+2)/(q_k+2+y))^2 ≤ 1`, and its fixed point is
> `α_k = (q_k^2+2q_k)/q_{k+1}` up to `|ψ_k(α_k) - α_k| = α_k(1-α_k)/q_{k+1}`.
> Hence `δ_k ≤ c_k δ_{k+1} + d_k` with `c_k = (α_k q_k/q_{k+1})^2` and
> `d_k = α_k(1-α_k)/q_{k+1}`, so `δ_k ≤ η_k := Σ_{j≥k} (Π_{i=k}^{j-1}c_i) d_j`,
> an absolutely convergent series (`c_k ≲ 1/4`, `d_k` doubly exponentially
> small). `|log s_k - log α_k| ≤ δ_k/(min(s_k,α_k)) ≤ 2δ_k` since
> `s_k, α_k ∈ [1/4, 1/2]`. The second sum: `|log c_k - log s_k| = log(1+s_k r_k)
> ≤ s_k r_k ≤ r_k`, and `Σ r_k ≤ 2/q_1` by (1). ∎
>
> *Machine check (§A):* the observed `|s_k - α_k|` agrees with the universal
> bound `η_k` to ~10 significant digits at every `k`
> (e.g. `k=1`: `2.709e-3` vs `1.786e-6` — see the transient note below;
> `k=2`: `4.168e-6` vs `4.254e-12`; `k≥3` agree to all printed digits).
> The finite-prefix transient decays as `|ψ(1)-ψ(0)|·c_0^{N-k}` and is
> `O(10^{-11})` at `k=2` for `N=10`.

> **Theorem 3 (main — PROVED).** There exists `x ∈ (0,1)` such that the greedy
> orbit of `x` has `limsup_{K} (1/K) Σ_{k<K} log c_k ≥ -0.76` and
> `liminf_{K} (1/K) Σ_{k<K} log c_k ≤ -1.21`; in particular
> `(1/K) Σ_{k<K} log c_k` **has no limit**.
>
> *Proof.* By Theorem 2 the running mean of `log c_k` differs from that of
> `log α_k` by at most `2B ≤ 4·10^{-3}` uniformly in `K`, so it suffices to
> show the prescribed mean does not converge. Let `S_j = M_0 + ... + M_{j-1}`
> be the block ends and write `w_j := M_j/S_{j+1} ∈ [1 - 1/r, 1]`. Because
> `Σ_{k<S_j} log α_k = (Σ_{i<j} M_i m_i)` with `m_i` constant on block `i`,
>
> ```
> A_{S_{j+1}} = w_{j+1} m_{j+1} + (1 - w_{j+1}) A_{S_j}.            (2)
> ```
>
> Along the block ends this is a two-term alternating linear recursion whose
> even and odd subsequences converge to the two fixed points
> `a = (m_0 + μ m_1)/(1-μ^2)`, `b = (m_1 + μ m_0)/(1-μ^2)` with `μ = 1-w`.
> For the concrete pattern `M_j = 3^j`, `m_0 = log(1/2)`, `m_1 = log(1/4)`
> one gets `a = -0.9704` and `b = -1.1090`, so
> `limsup ≥ -0.971`, `liminf ≤ -1.109`; more safely, the even/odd limits are
> `(-1.06, -0.91)` and `(-1.11, -0.97)` for every ratio `r ≥ 3`, giving
> `limsup ≥ -0.91`, `liminf ≤ -1.11`. A limit `C` of the full running mean
> would force `A_{S_j} → C` (the tail average is dominated by
> `A_{S_j}`), contradicting the two distinct subsequential limits.
>
> For the survey's own pattern (`M_j = 10^j`, `α` alternating `1/2, 1/4`) the
> block-end means are
> `-0.6931, -1.3233, -0.7556, -1.3233, -0.7562, -1.3233, ...`, i.e. they
> converge to the 2-cycle `{-0.7562, -1.3233}` (§E): again no limit. ∎

*Exact check of the oscillation (`Fraction` arithmetic in
`lib/tpp_no_limit_orbit.py`, mpmath at 30–100 digits in the compute script):*
for `M_j = 3^j`, `α = 1/2, 1/4` the block-end means come out
`-0.6931, -1.2130, -0.8531, -1.2130, -0.8650, -1.2130, -0.8663, -1.2130`;
the two subsequential limits are `-0.8665` and `-1.2130`, gap `0.347`, and the
printed `±2B ≈ ±3.1e-3` cannot cancel it.

### 1.4 Honest limitations

* The rigorous error bound `η_k` is computed for the *infinite* backward
  sequence; the finite-prefix seed realises the word exactly and its `s_k`
  agree with the limit to `O(c_0^{N-k})`, so for the practical `N ≥ 10` used in
  §A the two are indistinguishable at the printed precision. The statement of
  Theorem 2 is about the limiting orbit; the machine check covers the finite
  seed. Both are exact-rational.
* The `2B ≤ 3.1e-3` figure is what the exact rational recursion
  `η_k = c_k η_{k+1} + d_k` gives for `q_0 = 8` with `δ_N = 0`; it is stated as
  such (no floating point enters it).

## 2. OP-33(a) — the precision floor

### 2.1 Verdict

**PROVED** (analytic bound) and **EVIDENCE** (the measured table). The survey's
direction is right; the constant is now explicit.

### 2.2 The lemma

> **Lemma (PROVED).** Let `x ∈ (0,1)`, `r_0 = x`, and
> `r_{k+1} = r_k - 1/⌈1/r_k⌉` while `r_k > 0`. Fix `D` with `10^{D} ≥ 2`
> (e.g. `D ≥ 1`) and let `K` be the first index with `r_K < 10^{-D}` (so `K` is
> the number of usable forward steps at `D` decimal digits). Then
> `K ≤ log_2(D+1) + 2`.
>
> *Proof.* Since `q_k := ⌈1/r_k⌉ - 2 ≥ 1` one has `1/(q_k+2) ≥ 1/(q_k+3)
> ≥ r_k/2` (because `r_k ≤ 1/(q_k+1)`), hence `r_{k+1} ≤ r_k²/2 ≤ r_k²`.
> By induction `r_k ≤ r_0^{2^k} < 10^{-2^k}`. Since `r_{K-1} ≥ 10^{-D}`
> (minimality of `K`), `2^{K-1} < D + 1`; hence `K - 1 < log_2(D+1)` and
> `K ≤ log_2(D+1) + 2`. ∎

The same proof gives the exact-rational skeleton used for the Lean attempt:
if `r_0 ≤ 1/10`, `r_{k+1} ≤ r_k²` and `10^{-D} < r_{K-1}`, then
`2^{K-1} ≤ D`, i.e. `D + 1 ≤ 2^{K-1}`.

## 3. OP-33(b) — the finite-`r` means at ≥ 10⁴ prescribed steps

### 3.1 The route and the result

The forward orbit cannot be iterated past `≈ log₂ D` steps (§2), so the means
are taken along the *prescribed* word built backwards, which is realisable by
Theorem 1 and has `s_k → α_k` by Theorem 2. On the 10⁴-step scale
(`op28_30_33_compute.py` §C):

| pattern | mean `log c_k`, 10⁴ steps | = −1? | mean `log α_k` |
|---|---|---|---|
| `α = 1/2` constant | **−0.6931471806** | no | −0.6931471806 |
| `α = 1/3` constant | **−1.098612289** | no | −1.098612289 |
| `α = 1/4` constant | **−1.386294361** | no | −1.386294361 |
| `α = 9/10` constant | **−0.1053605157** | no | −0.1053605157 |
| `α = 1/10` constant | **−2.302585093** | no | −2.302585093 |
| blocks `1/2,1/4` (`3^j`) | **−1.213007566** | no | −1.213007566 |
| survey blocks `1/2,1/4` (`10^j`) | **−0.7555928725** | no | −0.7555928725 |

The running means are stable to all printed digits over 10³–10⁴ steps for
every pattern (e.g. `α = 1/2`: `−0.6931472` at every checkpoint). The
self-test in §C also verifies **exactly** (rationals) that the self-consistent
word is realised.

> **Statement (PROVED for the family, EVIDENCE for the individual numbers).**
> For the prescribed-word construction with target pattern `(α_k)`, the
> running mean of `log c_k` converges to the Cesàro mean of `log α_k`
> (the difference is bounded by `2B` of Theorem 2 plus the `o(1)` of the
> Cesàro average). Hence the finite-`r` means attain **every** value in
> `[liminf mean log α_k, limsup mean log α_k]`; in particular they are not
> identically `−1`. The limit `−1` is produced by the *annealed* (uniform-`x`)
> average (register K6i), not by any single `x`.

### 3.2 The source's "not −1" claim, adjudicated

Row I8 reads: *"the finite-`r` means are not `−1`; but measured on 7–13 steps
before underflow, so no convergence claim follows."* Two separate facts are
being conflated:

1. **There is no universal value at all.** Register K6f already proved this
   with `q_{k+1} = 2q_k²` (`s_k → 1/2`, limit `log(1/2) = −0.6931`), and §3.1
   extends it to an arbitrary prescribed pattern. So "not `−1`" is true but
   for the reason that *nothing* is universal; `−1` is only the average over
   `x`.
2. **The finite-time gap.** For any finite `K`,
   `(1/K)Σ_{k<K} log c_k = (1/K)Σ log s_k - (1/K)Σ log(1+s_k r_k)` with
   `Σ_k log(1+s_k r_k) =: Γ ∈ (0, Σ 1/q_k]` finite and positive. Hence the
   finite-`r` mean is **always strictly below** the limiting `s`-mean, by
   exactly `Γ_K/K`. With `K ≤ 15` (the reachable range) this gap has not had
   time to vanish, and with `s_k` still in the transient (`s_k` not yet equal
   to `α_k`, let alone to the annealed mean `1/2`) the measured number is
   genuinely far from `−1`.

Reproducing the source protocol (`probes.py` probe 5, §D) at 120 dps gives
**8 usable steps** and mean `−0.5053`, whereas the limit for that orbit is
`≈ log(1/2) = −0.6931`. So the finite-`r` mean is not `−1`, is not `log(1/2)`
either, and **no** statement about the limit can be read off it — exactly the
source's own caveat, now with a mechanism.

**Verdict for OP-33(b): EVIDENCE for the tabulated limits (they follow from
Theorems 1–2, which are PROVED); the source's "not −1" is confirmed but
re-attributed.**
