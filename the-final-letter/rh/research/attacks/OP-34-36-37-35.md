## 1. TASK 1 — OP-34 + OP-36: exact `p(L)` via the window-class union

Notation: `S = {a_0<…<a_m} ⊂ [0,N-1]`, `d_i = a_{i+1}-a_i`, `span = a_m-a_0`.
For `t ∈ [0,N-L]`, `factor(t) = (a-t : a∈S, t≤a≤t+L-1)` and
`p(L) = #{factor(t)}`. The window class of `t` is `(i(t),j(t))`, the indices of
the first and last one in the window.

### 1.1 The survey's refutation is correct (and understates the failure)

`lib/tpp_window_class.class_sum_formula` implements the survey's reading of the
`[DREAM]` sum ("class size" = number of factors in the class = number of windows
in the class, plus a `+1` for the all-zero factor). I re-derived every quantity
independently:

* for `1/π = (2,13,607)`, `N=1400`, the reading
  `[∃ all-zero] + Σ_{(i,j)} #windows in class` disagrees with `p(L)` on
  **604 / 1399** values of `L` (all over-counts), and the `(i,j)` classes are
  **non-disjoint on exactly those same 604** `L`. The survey's headline number is
  reproduced exactly. **REFUTED.**
* Agent A's formula **as literally written**, `1 + #{}(L>span) + Σ_{i≤j} T(i,j)`
  with `T(i,j)=max(0, min(a_i,a_{j+1}-L) − max(0,a_{i-1}+1,a_i-L+1) + 1)`,
  over-counts on **1399 / 1399** `L` for `1/π` (e.g. `L=1`: formula 7, `p=2`;
  `L=605`: formula 612, `p=609`). Reason: the interval in `T(i,j)` is
  `[max(0,a_{i-1}+1,a_i-L+1), min(a_i,a_{j+1}-L)]`, which counts windows with
  first index `i` and last index **at most** `j`; summing over all `j≥i` counts a
  window with last index `J` exactly `m-J+1` times. So the author's own "1–2 %
  over-counting" self-report is far too optimistic: the literal formula is off on
  every `L`.

**Verdict: REFUTED, both readings.** The class decomposition is a correct
*partition* of the windows; the defect is exactly class-disjointness (below).

### 1.2 The exact collision criterion — PROVED

For a nonempty window `t` define

* `i = i(t)`, `j = j(t)`;
* `x(t) = a_i - t` (offset of the first one);
* `shape(t) = (0, a_{i+1}-a_i, …, a_j-a_i)` (partial sums of the gap run
  `g_i,…,g_{j-1}`).

**Lemma 1 (factor = offset + shape).** `factor(t) = x(t) + shape(t)` as sets.

*Proof.* `a∈S∩[t,t+L-1]` ⟺ `a = a_{i+r}` for a unique `0≤r≤j-i`; then
`a-t = x(t) + (a_{i+r}-a_i)`. The right-hand partial sum obeys
`0 ≤ a_{i+r}-a_i ≤ a_j-a_i ≤ L-1-x(t)`. ∎

**Theorem 2 (collision criterion).** For two windows `t,t'`,
`factor(t)=factor(t')` **iff** `x(t)=x(t')` and `shape(t)=shape(t')`.

*Proof.* (⇐) Lemma 1. (⇒) Both factors are nonempty with the same minimum
`x(t)=x(t')` (as `0∈shape`), hence subtracting the minimum gives
`shape(t)=shape(t')`. ∎

This is the "local periodicity of the support" the survey was looking for: two
windows collide exactly when the same gap run occurs at two first-one positions
at the same window offset. At the class level it reads:

**Corollary 3 (class-level criterion).** Two distinct classes `C=(i,j)`,
`C'=(i',j')` carry a common factor **iff**
1. `j-i = j'-i'`,
2. the gap runs `(g_i,…,g_{j-1}) = (g_{i'},…,g_{j'-1})`, and
3. the offset intervals `X(C), X(C')` intersect, where

```
X(i,j) = [ max(0, a_i-(N-L), L-(a_{j+1}-a_i)),  min(d_{i-1}-1, L-1-(a_j-a_i), a_i) ]
```

with conventions `a_{m+1}=∞`, `d_{-1}=∞`, and the class window-start interval is
`T(i,j) = [max(0,a_{i-1}+1,a_j-L+1), min(a_i,a_{j+1}-L,N-L)]`.

*Proof.* (⇒) a common factor has a well-defined `(x,shape)`; it is produced by a
window of each class, so `x∈X(C)∩X(C')`, and 1–2 follow from equality of shapes.
(⇐) take `t=a_i-x`, `t'=a_{i'}-x`; condition 3 makes them valid window starts in
their classes, and 1–2 make the factors equal. ∎

### 1.3 The corrected exact class sum — PROVED

**Theorem 4 (exact complexity).** Write `C` for the nonempty `(i,j)` classes and
group them by their shape `P`:

```
p(L) = [∃ an all-zero window] +  Σ_{shapes P}  | ∪_{C : shape(C)=P} X(C) | .
```

*Proof.* By Theorem 2 the map `factor ↦ (x,shape)` is well defined and
injective, so distinct shapes have disjoint factor sets (two factors with equal
minimum `x` and different shapes cannot agree). For a fixed shape `P` the factors
produced are exactly `{x+P : x ∈ ∪X(C)}`, and `x↦x+P` is injective; hence the
number of distinct factors of shape `P` is the cardinality of that union. Adding
the single empty factor when a window avoids the support gives the claim. ∎

So the requested form `p(L) = 1 + [empty] + Σ_classes |distinct factors per
class|` **is exact**, provided "class" is the **shape group** (gap run) and the
per-class counts are combined by **union of the offset intervals**, not by a
sum. Equivalently: the `(i,j)` labels are too fine by exactly the collisions of
Corollary 3; the correct class invariant is the shape.

Notes.
* `[∃ all-zero window]` has the closed form `L ≤ max(a_0, max_j(d_j-1), N-1-a_m)`
  (proved in §2b).
* For a fixed shape the union `∪X(C)` need not be an interval, but it is a finite
  union of explicit integer intervals; there is no hidden step.
* This also explains the survey's `604`: those are exactly the `L` at which some
  two `(i,j)` classes share a shape **and** overlap, i.e. the naive sum misses the
  union correction.

## 2. TASK 2 — OP-37: the `(i,x)` repair

### (a) Realisability — PROVED

**Theorem 5.** Fix `S,N,L` and an index `i`. The pairs `(i,x)` realised by some
window (with `i` the first-one index and `x=a_i-t` its offset) are exactly

```
max(0, a_i-(N-L)) ≤ x ≤ min(d_{i-1}-1, a_i, L-1)      (d_{-1}=∞).
```

*Proof.* `t=a_i-x`. `t∈[0,N-L]` ⟺ `a_i-(N-L) ≤ x ≤ a_i`.
`a_i` is in the window ⟺ `0≤x≤L-1`. No earlier one is in the window ⟺
`a_{i-1}<t=a_i-x` ⟺ `x<d_{i-1}` (for `i=0`, vacuous), and this automatically
excludes every `a_k`, `k<i`. Intersecting gives the range. ∎

This is exactly the source's `0≤x≤min(d_{i-1}-1,a_i,L-1)`, `a_i-x≤N-L`
(the latter is the lower bound). **The survey's 0/95826 is reproduced**: over the
survey's loop (`N2∈[3,19]`, `1..3` ones, all `L`) there are **95 826** cases and
**0** mismatches; my own helper/sweep agrees.

*Caveat on the source's "tail" phrasing.* The sentence "for `L>span` the factor
is the tail `{x+(a_j-a_i): j≥i}`" is only literally true when the whole right
tail fits the window, i.e. `x+(a_m-a_i) ≤ L-1`; otherwise the window truncates
the tail. The realisability pair conditions themselves are unaffected and exact.

### (b) The all-zero criterion — source REFUTED, corrected form PROVED

**Theorem 6.** A length-`L` window meets no support point **iff**

```
L ≤ max( a_0 ,  max_j (d_j - 1) ,  N - 1 - a_m ).
```

*Proof.* The complement `[0,N-1]\S` is a disjoint union of maximal runs of
lengths `a_0` (initial), `d_j-1` (internal, `j=0..m-1`), `N-1-a_m` (final). An
integer interval of length `L` avoids `S` iff it is contained in one of these
runs, iff `L ≤ max` of the run lengths. ∎

The harvested criterion `L ≤ N-a_m-1` is only the final-run condition, hence
false in general. **Witness: `S=(0,4)`, `N=6`, `L=3`** (the window `[1,3]`
avoids both ones, while `N-a_m-1 = 1 < 3`). Over the survey's loop this source
criterion is wrong on **24 337** of the 95 826 cases; the corrected form is wrong
on **0**. Both counts reproduced exactly.

### (c) Injectivity — source REFUTED, corrected form PROVED

The source's plateau claim ("on the plateau these tails are distinct") is false
as a statement about realisable pairs in general. **Witness:
`S=(12,20)`, `N=26`, `L=12`**: the pairs `(0,7)` and `(1,7)` are both realisable
and both give the factor `(7,)` (windows `t=5` and `t=13`). The survey's witness
is confirmed.

The corrected, hypothesis-free statement is:

**Theorem 7 (corrected injectivity).** If `p(L) ≥ a_m+2`, the map
`window start t ↦ factor(t,L)` is injective on the nonempty windows.
Equivalently the map `(first-one index, offset) ↦ factor` is injective.

*Proof.* Every nonempty window contains a one `a≤a_m` with `t≤a`, hence starts
at `t≤a_m`; so there are at most `a_m+1` nonempty windows, while every window
factor is either `∅` or the factor of a nonempty window. If two distinct
nonempty windows had the same factor, the image of the nonempty windows would
have at most `a_m` elements, so

```
p(L) ≤ #(nonempty image) + 1 ≤ a_m + 1 < a_m + 2,
```

contradiction. ∎

So on the (true) plateau `p(L) = max`, injectivity holds, and the survey's
`N ≥ 2a_m+3` is only needed to know that the plateau value is `a_m+2` (or that a
plateau exists) — not for the injectivity argument itself. This is stronger than
the survey's `0/15087` evidence:

## 3. TASK 3 — OP-35: the deficit form

**`S_{1,k}` is undefined corpus-wide.** A full grep of the repository
(`--include=*.md --include=*.py --include=*.lean`) finds the symbol only in the
same two source prose mentions (`rounds/rh40/rounds/round01_agentA.md:27,75`)
plus downstream quotations of that sentence; the `[LEAP]` phrase "gap-chain sums
`S_{1,k}`" is the only other occurrence and defines nothing. The index base of
`d_j` is also never fixed (0- or 1-based), so the expression is doubly
ambiguous. **Verdict: undefined / not testable as stated.**

**The natural reading is REFUTED.** Reading `S_{1,k} = Σ_{i≤k} d_i` (1-based
gaps `d_1=11, d_2=594` for `1/π`) gives

```
D(L) = max_j (L - d_j - 1 - S_{1,j-2})₊
     = max( (L-12)₊ , (L-595)₊ , … ) = (L-12)₊ .
```

Measured first differences of `p` for `1/π`, `N=1400`:

```
slope runs (L_first, L_last, p(L+1)-p(L)) = (1,10,1), (11,13,2), (14,604,1), (605,791,0), (792,1399,-1)
```

i.e. the `2→1` drop is at `L=14` (`p(13)=16, p(14)=18, p(15)=19`), so the
deficit must satisfy `D(13)=0`, `D(14)=1`, `D(15)=2, …`. The natural reading has
`D(13)=1`, one step too early. This is the exact off-by-one the survey reports.

Two further points:
* No partial-sum convention for `d_j` can repair the turn-on by itself: to get
  `D(13)=0` the `j=1` term must be `L-13-S`, i.e. `S_{1,-1}=1` under the natural
  indexing, which contradicts `S_{1,k}=Σ` (empty sum `0`). The source supplies no
  constant term.
* The natural `D` is unbounded (`D(604)=592`), whereas a "deficit that eats the
  pair slope back" should be a count of cancelled pair classes, bounded by the
  number of gaps. The formula describes the right *rate* on `[14,604]` only
  accidentally (base slope 2 minus an increment of 1) and has no mechanism to
  stop at the plateau (`L=605`), where the measured slope is 0.

**Verdict: the natural reading is REFUTED by the `1/π` slope runs (turn-on `L=13`
vs measured drop `L=14`); `S_{1,k}` remains undefined, so the item is not
testable as stated.** (A repaired `D` would have to be a bounded, stepwise
function of the gaps; none is derivable from the source.)
