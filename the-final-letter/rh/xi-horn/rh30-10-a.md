# rh30 §10 (a) — the collapse: the exact statement, the false part, and the fourth route

The arc's one universally quantified claim, taken directly. rh30 §10 (a) asked
for a proof that λ_min/E_h(0) is a function of n/N_eff — or, failing that, for
the weak version:

> λ_min ≥ c·E_h(0)·F(n/N_eff) with F explicit and positive below 1 — which
> "would cover every window in the family at once."

It has been open since rh30 and untouched through rh31–rh39 (rh38 §9 (a): "open
eight documents"; rh39 §8: "there is no proof here"). This file takes it, and
returns four things: the statement's exact form, a **refutation of the literal
claim**, a **new lower bound** built from the one property every previous bound
discarded, and a measurement showing that the new bound **fails too — earlier
than the bound it was meant to beat.** The last is the useful part, because it
identifies what all four routes have in common, and it is not what rh30 §5 said
it was.

**Nothing here proves the collapse.** §7 says exactly what is left.

**What is conditional.** The measure picture is rh29's and is conditional on RH
(rh30 §0). Theorems 1–4 are unconditional statements about an arbitrary
positive measure on the circle; only their application to μ inherits RH. The
numbers in §6 are computed on a **surrogate window** — a plain sinc⁴, not
rh27a's searched window — so they are not certificates and no λ_min here is one
of the arc's nine. §6 opens by validating the surrogate against three numbers
rh30 published.

---

## 1. The object, stated exactly

From rh29 §3 and rh30 §1: under RH the certified matrix is

```
T_n[j][k] = E_h((j−k)Δ′),     E_h(v) = Σ_ρ ĥ(γ_ρ)²cos(γ_ρ v)              (1)
```

— the moment matrix of the purely atomic measure

```
μ = Σ_ρ ĥ(γ_ρ)²·δ  at  γ_ρΔ′ mod 2π,      ‖μ‖ = E_h(0)                   (2)
```

the window setting the weights, the mesh the positions. Write

```
A(ℓ) = min { μ(I) : I an arc of length ℓ }        the emptiest-arc mass     (3)
N_eff = ‖μ‖ / (2 max_γ ĥ(γ)²)                     rh30 §2                   (4)
```

and let g_max be the largest gap between consecutive atoms, ℓ_max the largest
arc of the Voronoi partition they induce. Throughout, D = n − 1.

---

## 2. The exact form of the problem

Everything below rests on one rewriting, and it is the rewriting that makes
"uses q ≥ 0" a definite phrase rather than a wish.

> **Theorem 1.** For any finite positive measure μ on 𝕋,
> ```
> λ_min(T_n(μ)) = min { ∫q dμ : q ≥ 0, q a trig polynomial of degree ≤ n−1,
>                                (1/2π)∫q dθ = 1 }                          (5)
> ```

*Proof.* λ_min = min over ‖c‖₂ = 1 of c*T_nc = ∫|p|²dμ with p = Σ_{k<n}c_ke^{ikθ},
and ‖c‖₂² = (1/2π)∫|p|²dθ. By Fejér–Riesz the set {|p|² : deg p ≤ n−1} is
exactly the set of non-negative trig polynomials of degree ≤ n−1. ∎

Verified: the minimising eigenvector's q = |p|² has min q = 1.6e−9 ≥ 0, mean
1.0000000000, and ∫q dμ = λ_min to 12 digits.

Three consequences, and they organise the whole file.

**(i) It is one linear program.** (5) is a linear objective over the cone of
non-negative trig polynomials, and its dual is `max{t : T_n − tI ⪰ 0}` — λ_min
again. There is no reformulation waiting to be found: every bound is a
*relaxation*, and a relaxation is chosen by deciding which property of q to
keep.

**(ii) rh30 §5's three routes are three relaxations that keep the same
property.** Gershgorin keeps Σ|E_h(kΔ′)|; Koksma keeps the total variation of
q; Marcinkiewicz–Zygmund keeps ‖q′‖₁ through Bernstein. All three replace
"q ≥ 0" by a bound on how fast q moves, which is why rh30 §5 ended: *"What is
missing is an inequality that uses q ≥ 0 rather than only its variation."*

**(iii) The relaxation is where the loss lives, so the loss is nameable.** §4
builds the first relaxation in the arc that keeps positivity itself, and §6
measures what that buys. The answer is: less than route two, and §7 says why.

## 3. The literal claim is false

> **Theorem 2.** There is no function F with λ_min/‖μ‖ = F(n/N_eff), and none
> with λ_min ≥ c‖μ‖F(n/N_eff) for F positive below 1.

*Proof.* N_eff is a statement about the weights alone (rh30 §2, asserted there
to 1 part in 10¹²). Fix the weights and n; then n/N_eff is fixed while λ_min
ranges over four decades. Computed, at N = 400 atoms with weights w_k = k^{−2}
and n = 25 throughout, λ_min/‖μ‖ is

```
  positions scattered on the circle          1.035e−02
  positions on an exact grid, weights winding monotonically   1.813e−03
  positions clustered in an arc of length 0.05                0   (−1.8e−15)
```

The third is exactly zero: a degree-24 polynomial can be made uniformly small on
a short arc, so the whole measure is annihilated at n/N_eff far below 1. ∎

This is not a new phenomenon so much as an unnoticed one. **rh30's own §5
contains the counterexample**, three sections before the claim: its four
controls at Δ′ = 0.12, n = 151 include

```
  true positions, true weights — the arc        λ_min/‖μ‖ = 0.2846
  grid positions, true weights                  λ_min/‖μ‖ = 2.9433e−06
```

— identical weights, hence identical N_eff = 95.7, identical n, and λ_min
9.7×10⁴ apart. rh31 §3 later reported that the law "breaks off its native
family" and rh31 §7 listed "λ_min is not a function of n/N_eff" among the things
it is not. Both readings are right; what neither said is that rh30 §10 (a) was
therefore **unprovable as written from the moment it was written**, and that the
nine documents which left it open were leaving open a false statement.

What survives is the conditional form: **the collapse is a law about the arc's
own family**, whose positions are {γΔ′ mod 2π} and are equidistributed
unconditionally (Hlawka, via rh30 §5). Any proof must carry a positional
hypothesis. Theorems 3 and 4 carry the weakest one that has any content — the
arc-mass function A of (3).

---

## 4. The two facts about q ⪰ 0 that no variation bound uses

Let q be feasible for (5), D = n−1, M = ‖q‖_∞, and write q = |p|².

**(F1) 1 ≤ M ≤ n.** Mean 1 forces max ≥ 1; Cauchy–Schwarz on n coefficients
gives |p| ≤ √n·‖c‖₂ = √n.

**(F2) The peak has width.** |p| is Lipschitz with constant D‖p‖_∞ = D√M
(Bernstein, applied to e^{−iDθ/2}p and then undone). Hence for s ∈ (0,1),

```
q ≥ M(1−s)²   on the arc  |θ − θ*| ≤ s/D  around any peak θ*               (6)
```

Verified: Lip(|p|) = 5.991 against the bound D√M = 23.706; on the arc of
half-length 1/(2D) the measured min of q is 8.557 against M/4 = 2.195.

**(F3) The level sets are few and long.** For t ∈ (0,1),

```
|{q ≥ t}| ≥ 2π(1−t)/M,  and {q ≥ t} is a union of at most D arcs            (7)
```

— the first from 2π = ∫q ≤ t(2π − |E|) + M|E|; the second because a trig
polynomial of degree D takes the value t at most 2D times.

Neither fact is available to a variation bound: both are statements that a
non-negative normalised polynomial *cannot be small everywhere*, and both are
false for signed q of the same degree. There is a third, used only in the
proof's bookkeeping — for every rotation θ₀ the n-point grid quadrature is
**exact**,

```
(1/n)Σ_{r<n} q(θ₀ + 2πr/n) = 1                                             (8)
```

verified to 2.7e−15 over 50 rotations. (8) has no error term at all, which is
what makes it tempting; §7 records why it cannot be used on its own.

## 5. The floor

> **Theorem 3.** Let Ǎ be the convex envelope of A on [0, 2π]. Then for every
> n ≥ 2, with D = n−1,
> ```
> λ_min(T_n(μ)) ≥ min      max { max  M(1−s)²·A(2s/D) ,                     (9)
>                 1≤M≤n           s∈(0,1)
>                                 max  t·D·Ǎ( 2π(1−t)/(MD) ) }
> ```                              t∈(0,1)

*Proof.* Fix a feasible q and let M = ‖q‖_∞, which lies in [1, n] by (F1). The
first branch is (6) integrated against μ: the arc it produces has length 2s/D,
so ∫q dμ ≥ M(1−s)²·A(2s/D). For the second, put E = {q ≥ t}; then
∫q dμ ≥ t·μ(E). By (7), E is a union of k ≤ D disjoint arcs of lengths ℓ₁…ℓ_k
with Σℓ_i ≥ 2π(1−t)/M, so μ(E) = Σμ(I_i) ≥ ΣA(ℓ_i) ≥ ΣǍ(ℓ_i) ≥ k·Ǎ(Σℓ_i/k).
Ǎ is convex with Ǎ(0) = 0, so Ǎ(x)/x is non-decreasing and k·Ǎ(S/k) is
non-increasing in k; since k ≤ D this is ≥ D·Ǎ(2π(1−t)/(MD)). Both branches hold
for every feasible q, M is not ours to choose, and the minimiser of (5) is
feasible. ∎

Three properties worth stating, because they are what the bound was built for.

- **It needs no eigenvalue.** Its only input is the arc-mass function A —
  elementary, computable from a sorted list of atoms. This is what rh31 §8 (a)
  asked a lemma to deliver: "every emptiest-arc computation becomes a certified
  floor".
- **It needs no retention sweep**, though it accepts one (Theorem 4).
- **It is one-sided in the zero table.** More atoms only raise A.

> **Theorem 4.** If ν ≤ μ as measures then λ_min(T_n(ν)) ≤ λ_min(T_n(μ)).

*Proof.* T_n(μ) − T_n(ν) = T_n(μ−ν), the Toeplitz moment matrix of a positive
measure, hence PSD. ∎

So (9) evaluated on **any finite sub-table of ordinates is valid for the whole
measure**, with no tail estimate: truncating the zero table can only lower A,
and lowering A can only lower the floor. That is not true of λ_min itself, where
the cut at r = 4800 leaves rh29's residue of 1.38e−7 to be accounted for. It is
also the licence for the retention sweep — discarding light atoms is a legal
choice of ν, so (9) may be maximised over retention thresholds exactly as
rh30 §5 does for route two.

**Validity, checked.** 500 measures over five families (crystals, random
positions, random positions with w ~ U⁵ weights, equidistributed positions with
k^{−3} weights, two-cluster configurations), n from 2 to 60: **0 violations**,
78 non-vacuous cases, minimum ratio truth/bound 8.14.

(γ_4308 = 4799.673 — the arc's cut at 4800); weights ĥ(γ)² = sinc⁴(aγ), whose
r^{−4} envelope is rh30 §6's; a chosen per window so that N_eff reproduces
rh30 §2's ladder. Three of rh30's published numbers come back out of it:

```
  N_eff ladder                     7.00, 17.30, 95.70, 207.00, 467.30
                          rh30 §2: 7.0,  17.3,  95.7,  207.0,  467.3

The last is the sharp one: rh30's measured MZ reach is 1/ℓ_max to 0.3%, which

## 7. What the four routes have in common — and it is not what rh30 §5 said

rh30 §5's verdict was that all three of its bounds "lose linearly in n" because
they are worst-case over every polynomial with unit coefficients, and that
*"what is missing is an inequality that uses q ≥ 0 rather than only its
variation."* On this document's evidence that diagnosis is wrong, or at least
not sufficient, and the correction is the one thing here worth carrying
forward.

(9) is an inequality that uses q ≥ 0 — twice, and pointwise: (6) is the
statement that a non-negative polynomial's peak has width, and (7) that its
level sets are few and long. Neither survives dropping positivity. And (9)
still loses linearly, and dies **earlier** than the variation bound it was built
to beat.

What actually sets every death depth is visible in one line:

```
  Gershgorin  n ≈ 28   Koksma  n ≈ 12      [rh30 §5, at Δ′ = 0.12]
  route two   n = 1 + 1/ℓ_max = 228        (9)  n = 1 + 1/g_max = 131
  the truth at n = 261, where both are 0:  2.887 = 1.5% of ‖μ‖
```

Route two dies when the Bernstein transfer costs more than it carries — at the
largest Voronoi arc. (9) dies when an arc of length 1/D can miss every atom — at
the largest gap. **Both are the same quantity wearing two constants: the largest
hole in the atom set.** Neither has anything to do with which inequality was
chosen, and the truth walks past both without noticing, because at n = 261 a
degree-260 polynomial has 260 zeros against 8616 atoms and cannot put one in
every hole.

That is the separation, stated as sharply as this document can:

> Every bound the arc has built is a function of the **resolution** of the atom
> set — the size of its largest hole. The collapse is a law in the **count** —
> how many atoms the polynomial cannot annihilate. A bound whose only input is
> arc masses at scale 1/n is blind to the count by construction, and must die at
> the resolution whatever inequality generates it.

So rh30 §10 (a) is not merely open. It is **not reachable by any bound of the
kind the arc has been building**, and four attempts now agree on the reason. The
statement to go after is one whose input is the number of atoms a degree-(n−1)
polynomial must fail to suppress — which is exactly the "joint constraint across
many atoms rather than one at a time" that rh37 §7 and rh39 §4 arrived at from
opposite directions, and it is the first time three independent routes have
named the same missing object.

One route that looked open and is not: (8), the exact n-grid quadrature, has no
error term, and if the retained atoms were a rotated n-grid it would give
λ_min ≥ n·min_j w_j with no loss at all. It cannot be used, and the reason is
structural — the positive quadratures for Lebesgue measure exact to degree n−1
are *precisely* the rotated n-grids (one parameter, by the para-orthogonal
theory), and no rotation of a grid lands on the ordinates. Averaging over
rotations returns a measure with a density, which cannot be dominated by an
atomic μ. Recorded so that the fifth attempt is not this one.

## 8. What this document leaves

**(a) The count, not the geometry.** Prove a floor whose only positional input
is that no degree-(n−1) polynomial annihilates more than n−1 atoms. The
honest target, in the arc's own variables: λ_min ≥ ‖μ‖·F(n/N_eff) *for
equidistributed positions*, F explicit — the collapse with the hypothesis
Theorem 2 shows it must have carried all along. Failure branch, named in
advance: a family with equidistributed positions and λ_min collapsing well below
1 − n/N_eff, which would say the collapse needs more than equidistribution and
would be worth as much as the theorem.

**(b) The two branches of (9) are not sharp.** §6 fixes s = ½ in the first
branch, and (F1)'s upper end M ≤ n is used nowhere. Neither will change a
decade, and neither can move a death depth — both are set by g_max, which no
choice of (s, t) touches — which is why this document does not spend the
compute.

**(c) The certified set stays closed.** Nine, unchanged, renewed once more.
Nothing here certifies anything: §6's material is a surrogate window, and every
floor in it is below the truth by four to six decades.

## 9. Reconstruction

```
# --- the measure ------------------------------------------------------
gamma = first 4308 ordinates            # mpmath zetazero, gamma_4308 = 4799.673
w     = sinc(a*gamma)^4                 # surrogate window; a fixed by N_eff
atoms = (+-gamma*Dp) mod 2pi            # 8616 of them; weights w twice over
row[m]= 2 * sum_gamma w*cos(gamma*m*Dp) # = E_h(m*Dp);  T = row[|j-k|]

# --- A, the only input the floor needs --------------------------------
# A(L) = min over arcs of length L.  The minimum is attained by an arc whose
# left endpoint sits just past an atom, so it is one searchsorted per atom.
A(L) = min_j  mu( (t_j, t_j + L] )

# --- the floor, eq. (9) -----------------------------------------------
Ahat = lower convex hull of {(L, A(L))}      # grid MUST resolve g_max, else
                                             # the hull is positive where A is 0
                                             # and the floor is overstated
floor(n) = min over M in [1,n] of max( 0.25*M*A(1/(n-1)),
                                       max over t of t*(n-1)*Ahat(2pi(1-t)/(M(n-1))) )
# legal to evaluate on any sub-measure (Theorem 4) -> sweep a retention threshold
```

The one trap is flagged in the third line of the floor: sampling A on a grid
coarser than g_max makes the convex hull rise from the origin where A is
identically zero, which turns a dead bound into a live one. It cost this
document a full pass — the first run reported (9) alive at n = 601, and the
error was in the grid, not the theorem.
