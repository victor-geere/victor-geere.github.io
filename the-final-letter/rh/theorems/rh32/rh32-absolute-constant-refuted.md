# What died: λ<sub>min</sub> ≥ c·C<sub>n</sub>(μ) with absolute c is refuted

## Statement

> **What died.** "λ<sub>min</sub> ≥ c·C<sub>n</sub>(μ) with absolute c, in the bulk" is refuted by construction, on the arc's own material, with the counterexample demanded in advance by rh31 §8 (a). The failure is not a pathology; it is the prolate uncertainty principle doing exactly what it must.

The counterexample, from §4:

> There is no absolute constant; there is a function of the void width, and it dies at the prolate rate.

with the zeta-side instance:

> At K = 6 the searched window's own atoms, with one arc removed, give c = 3.5×10<sup>−6</sup>: **the measure rh31 ordered found is in hand, and it is the arc's own measure with one void.** Certificates die on voids, and on nothing else that thirteen documents of window search, five probes of this one, or 336 grid points have produced.

## Hypotheses and notation

- The refuted statement is rh31 §8(a)'s localisation lemma: λ<sub>min</sub> ≥ c·C<sub>n</sub>(μ) for an absolute constant c in the bulk ([rh31-localisation-conjecture](../rh31/rh31-localisation-conjecture.md)).
- The counterexample is any measure with a void (an arc empty of atoms) wider than about two kernel wavelengths; on the crystal the mechanism is exact.
- K = nW/2π is the void's time-bandwidth; c = c(K) = λ<sub>min</sub>/C<sub>n</sub> dies at the prolate rate.

## Proof / evidence

Refutation by construction, on the crystal (exact via [rh32-void-identity](rh32-void-identity.md)) and on the arc's own wrapped ordinates (searched window at mesh 0.12, n = 61, one arc removed: c = 3.5×10<sup>−6</sup> at K = 6), while c falls six decades. The source notes the failure was named in advance by rh31 §8(a) ("Fail honestly: find the measure that drives c to zero").
