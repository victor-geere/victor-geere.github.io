# Glossary

## Arithmetic

| Symbol | Meaning |
|---|---|
| `λ(n)` | Liouville function, `(−1)^{Ω(n)}`; completely multiplicative. |
| `μ(n)` | Möbius function. |
| `Λ(n)` | von Mangoldt function. |
| `Ω(n)` | number of prime factors of `n` counted with multiplicity. |
| `S_h(x)` | `Σ_{n≤x} λ(n)λ(n+h)`, the shifted Liouville correlation. |
| `C(K)` | the shift-2 odd core `Σ_{k≤K} λ(2k−1)λ(2k+1)`. |
| `S(x)` | the two-point correlation `Σ_{n≤x} λ(n)λ(n+2)`. |
| `π₂(x)` | the twin-prime counting function. |
| PNT | prime number theorem; `Σ_{n≤x}λ(n)=o(x)` is equivalent to it. |
| Chowla | `Σ λ(n+h₁)⋯λ(n+h_k)=o(x)`; open for `k≥2`. |
| Sarnak | Möbius-disjointness of zero-entropy sequences; open in general. |
| Parity barrier | Selberg’s principle that purely sieve-theoretic information cannot distinguish even/odd `Ω`; the obstruction to twin primes. |

## The greedy word

| Term | Meaning |
|---|---|
| Greedy harmonic sine | the word generated by greedily selecting harmonic angles `π/(n+2)` to represent a target. |
| Greedy word | the resulting `0/1` digit sequence. |
| `p(L)` | the factor-complexity law of the word: number of distinct factors of length `L`. |
| `span`, `a_m` | support endpoints used in the complexity law. |
| Plateau | the range where `p(L)=a_m+2`. |
| C1 regime | the range where `p(L)=L+1`. |
| Sylvester-sparse | support satisfies `m_{i+1} ≥ m_i(m_i−1)+1`; density `≈3.9·10⁻⁵`. |
| Tau alphabet | the signed alphabet with parity-locked support. |

## Budgets and reachability

| Term | Meaning |
|---|---|
| Budgets `P,N` | `P=2^{−p}ζ`, `N=(1−2^{−p})ζ−1`; `P+N=ζ−1`, `P−N=1−η`. |
| Brown’s criterion | sub-sums fill `[0,A]` iff `a_k ≤ T_{k+1}` for all `k`. |
| `n_min(p)` | the smallest index completing the budget; asymptotically `p/log 2 − 3/2 + O(1)`. |
| Reachable fraction `L(p)` | `measure(S₁)/P(p)`; asymptotic `p log p −(1+log log 2)p + …`. |
| Ceiling law | the false exact formula `nmin p = ⌈p/log 2 − 5/2⌉`. |

## Sums and zeros

| Term | Meaning |
|---|---|
| `S_N(t)` | the partial sum `Σ_{n≤N} n^{−1/2−it}`. |
| Balance | `Re S_N(t)=0`; equivalent to the equal four-part split. |
| Smoothing bridge | replacing the sharp cutoff by a weight `φ(n/N)`; does not remove `√N`. |
| `M_φ(s)` | `∫₀¹ φ(u)u^{−s}du`, the smoothing limit. |
| Explicit formula | Weil’s formula with the archimedean term; the corrected normalisation is in 006. |
| Route A | sign-change certificate for a unique simple zero. |
| Route B | Turing reduction: certified zeros plus a rigorous count force equality. |
| Route C | error assembly: residual bounded by the sum of three tails. |
| `N(T)` | zero count; `N(T)=θ(T)/π+1+S(T)` exactly. |
| Turing window | a certified finite height range (`T=15`, `T=33`); not RH. |

## Programme terms

| Term | Meaning |
|---|---|
| Finite-prefix indeterminacy | two functions agreeing on `[1,a)` can have opposite correlation asymptotics; no finite computation decides two-point Chowla. |
| Sign-blind | a rule described without reference to `λ`, `Ω`, or arithmetic data. |
| Positive-density coupling | a statistic `T` with `Σ_{n≤x}T(n)λ(n) ≢ o(x)`. |
| Log-arc rule | `A_I={n : log n mod 2π ∈ I}`; the well-posed OP-19 class. |
| `C_I(x)` | `Σ_{n≤x}1_{A_I}(n)λ(n)`. |
| OP-1…OP-19 | the programme-level open-problems register. |
| OP-20…OP-38 | harvest-level ids for finer-grained items; not promoted to the register. |
| X1–X6 | the six record corrections the programme harvest forced on the rounds. |
| P1–P19 | the positive ledger in the barrier capstone. |
| B1–B5 | the five bridges from the greedy sine to parity, all disposed of. |
| N1–N3 | the explicit non-claims. |

## Verification

| Term | Meaning |
|---|---|
| Lean | Lean 4 + Mathlib formalisation. |
| `sorry` | an unproved placeholder; the corpus has none. |
| `axiom` | an assumed declaration; the corpus has none. |

| `#print axioms` | the command that reports the axiom footprint. |

| OUT OF REACH | a literature reassessment found no current route. |
